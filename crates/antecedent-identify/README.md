# antecedent-identify

generalized adjustment envelopes, temporal pulse+sustained and temporal
mediation ID, Shpitser–Pearl ID/IDC (`IdIdentifier`, `IdcIdentifier`,
`AutoIdentifier`), path-specific effects, sharp binary-IV Balke–Pearl bounds,
pairwise backdoor for continuous-response functionals, and a certified subset
of single-source selection-diagram transport (unsupported cases return
`NotCertified`, not a false non-transportability claim).
