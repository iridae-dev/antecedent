# antecedent-design

Experiment and measurement design primitives: heuristic graph-channel entropy
(historically named EIG), unlock-list identification mass, OLS Gram SE reduction,
decision utility, and batched Monte Carlo candidate ranking.

`RankedCandidate.implemented_functional` names the mathematics actually scored.
These are not expected information gain or value of information under a likelihood
`p(y | G, design)` unless that functional is implemented.
