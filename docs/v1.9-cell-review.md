# 1.9 licensed-cell review — 2026-09-13

All 330 licensed cells in `parity/support_licensed.toml` were reviewed for
mathematical incorrectness, epistemic dishonesty (claims that exceed the code
or the evidence), and calibration gaps. The cells were split into fourteen
code-path families: static ATE (Frequentist / Bayesian), ConditionalEffect,
static graph-posterior mixtures, static responses,
mediation / path / distribution / counterfactual, derivatives, TemporalDag
Pulse/Sustained (Frequentist / Bayesian), DBN posterior, temporal class
envelopes (Frequentist / Bayesian), temporal mediation, and temporal
responses. Each family was reviewed independently against the source. Every
P0/P1 item below was then re-read against the code before inclusion; items
marked *verified* were re-traced line by line during consolidation.

No numbers were run: this is a read-only review. Calibration claims below are
about what the gate *can detect*, not measured coverage.

Tracking lives in `TODO.md` → 1.9 → "Licensed-cell review". IDs here (`R-n`)
are referenced from there.

## Summary

The shared mathematics mostly holds up. Estimator math re-derived correctly
for Hajek IPW (stacked sandwich), AIPW (ATE/ATT/ATC IFs, genuine
cross-fitting), Wald/2SLS (weak-IV SE suppression), stacked front-door, the
Abadie–Imbens matching variance, E-values, the NIG conjugate posterior,
draw-level envelope mixing (law of total variance, unidentified mass never
renormalized), the Riesz representer for the Gaussian-score ADE, local-
quadratic sandwich SEs, and the new shared circular-block between-atom SE in
f094d069.

The problems are concentrated in three places:

1. **A few intervals are computed with a resampling or variance scheme that
   ignores serial dependence**, on cells whose siblings already do it
   correctly (R-1, R-2).
2. **Validation and registry claims drift from the code**: refuters test the
   wrong target on multi-atom cells, prior sensitivity/PPC ignore the prior in
   force, and several limitations strings cite evidence that no longer
   exercises the claim (R-3 … R-13).
3. **The 1.9 calibration gate cannot yet detect the miscalibration it exists
   to catch.** The pass band accepts 71% coverage for a nominal-90% interval.
   The multi-atom DGPs are degenerate: atoms share one truth or collapse to a
   single completion. Every DGP is iid-Gaussian and correctly specified. Two
   assertions are vacuous (R-14 … R-18). Several TODO items checked for 1.9
   are not met as written because of this.

Most static cells (≈190 of 330) have no repeated-sampling coverage test at
all. The 1.9 TODO scoped calibration to temporal and mixture cells only
(R-19).

## A. Wrong or overclaimed numbers users see today

### R-1 · P1 · math · *verified* — Plain TemporalDag Frequentist SE ignores serial dependence

Cells: `PulseEffect`, single-step `SustainedEffect` × `TemporalDag` ×
{explicit, accepted} × Frequentist × {none, cheap, full} (12).

`temporal_path.rs:447` routes the single-window path to
`TemporalLinearAdjustment`, which delegates to the static `LinearAdjustmentAte`
(`temporal_adjustment.rs:296`). Its analytic SE is homoskedastic OLS
(`adjustment.rs:435`), and its bootstrap is an iid pairs bootstrap over
lag-aligned rows (`util.rs:186-194`, `ResamplingPlan::IidBootstrap`).
`bootstrap_replicates` defaults to 50, so this is the default path.

The adjacent cells already use dependence-preserving resampling:

- multi-step Sustained (`temporal_sequential.rs:678-701`)
- DBN / class envelopes (`execute_helpers.rs:486-519`)
- the `bootstrap.ci_coverage` refuter that checks this cell's interval
  (`bootstrap_refute.rs:57-94`)

When the adjustment set includes enough lagged outcomes, h=1 residuals can be
innovations, and iid is tolerable. For horizon h≥2, residuals are MA(h−1),
so both SEs are too small.

Fix: thread `ResamplingPlan::CircularBlock` (same block rule) into the
temporal problem's bootstrap. Report the block SE as the headline, or
NaN-gate the iid analytic SE the way temporal mediation does for Mediated.
Pair the fix with an AR(1) coverage test (R-17).

### R-2 · P1 · math/epistemic · *verified* — Temporal mediation Total/Direct SE is iid OLS

Cells: `TemporalMediationEffect` × {TemporalDag, TemporalCpdag} ×
{explicit, accepted} × Frequentist × {none, cheap, full} (12), for the Total
and Direct/NaturalDirect contrasts.

`temporal_mediation.rs:299-320` refuses the Mediated SE by default: it is NaN
unless `allow_iid_sobel_se` is set, because lagged rows are serially
dependent. Total and Direct always publish `coefficient_variance`, a
homoskedastic iid formula, on the same rows. `execute_temporal_mediation`
never bootstraps (`temporal_path.rs:773`, `bootstrap_replicates_ok: None`).

The same dependence argument applies to all three contrasts, but the policy
covers only one. Fix: use a shared circular-block bootstrap for all contrasts,
or apply the NaN-by-default gate to all three. Then state which contrasts
carry a dependence-honest SE in the limitations.

### R-3 · P1 · math/epistemic · *verified* — Multi-atom refuters test each atom against the pooled mixture

Cells: every Frequentist and Bayesian cheap/full cell that routes through
`run_envelope_effect_refuters` (`execute_helpers.rs:1021`), including:

- static PAG/CPDAG ATE (`pag_path.rs:259,469`)
- class-conditional CATE (`static_path.rs:1005`)
- static graph-posterior (`bayesian_path.rs:735,951`)
- DBN posterior (`bayesian_path.rs:1156,1516`)
- temporal class envelopes (`temporal_path.rs:2687,3329`)

The helper refits refuters on each atom's own estimand but passes the
mixture `EffectEstimate` as `problem.original`. For example,
`DataSubsetRefuter` then tests `replicate_p_value(&ates, problem.original.ate)`.
When a stable atom's effect differs from the pooled value, the atom "fails",
and `RefutationReport::mixture_weighted` requires unanimous pass. Every
fixture today has agreeing atoms (R-15), so this never shows up in tests.

The multi-step sequential path does this correctly
(`sequential_validation.rs:124-130` passes `&atom.estimate`).

Fix: pass each atom's own estimate. If the intended target is the mixture,
refit the whole mixture per perturbation on shared resamples instead. Pin the
behaviour with a heterogeneous-atom fixture.

### R-4 · P1 · epistemic · *verified* — `full` prior sensitivity ignores the staged prior

Cells: Bayesian `full` on static ATE (Dag / Cpdag / Pag) and every other
caller of `evaluate_bayesian_prior_sensitivity`.

`helpers.rs:1169` picks the α-grid only when `external_compose` is set. The
alternative is `PriorSensitivity::evaluate`, which constructs a fresh
estimator with `prior: None` (`bayesian_checks.rs:457-466`). A prior staged
via `cfg.prior` / `cfg.prior_artifact` determines the reported posterior, but
the sensitivity sweep perturbs an isotropic prior that was never used. No
test combines staged transfer with `RefuteSuite::Full`.

Fix: add a branch that perturbs the resolved prior (a variance-multiplier
grid), plus a regression test.

### R-5 · P1 · epistemic — Temporal prior-PPC ignores the prior in force

Cells: Bayesian `full`/`cheap` Pulse/Sustained × TemporalDag.

`temporal_path.rs:548-551` calls `PriorPredictiveCheck::new().check`, which
always builds `PriorSet::weakly_informative`. The static path uses
`check_with_prior` with the resolved prior (`bayesian_path.rs:116-124`). The
multi-step path in `sequential_validation.rs:150` also uses an isotropic
prior; that is honest only while multi-step transfer is refused.

Fix: resolve the prior once and route both PPC and sensitivity through it,
together with R-4.

### R-6 · P1 · epistemic — Temporal prior transfer is lag-blind

Cells: Bayesian Pulse/Sustained × TemporalDag × {explicit, accepted} (12).

`EstimandFingerprint` (`prior_bank.rs:27-34`) carries only query kind,
treatment, and outcome, with no lag, window, or horizon. For
`IdenticalCoefficientSubspace`, the catalog filter short-circuits
(`prior_bank.rs:566, 632-634`), and hydration binds coefficients by count and
index, not by name (`bayesian.rs:223-235`). A lag-1 Pulse posterior can bind
onto a different-lag target coefficient. That contradicts "incompatible
catalogs fail closed."

Fix: fingerprint the lag structure. Reject, or require a named mapping for,
index-only transfer when lag structure differs.

### R-7 · P1 · correctness · *verified* — `.graph()` after `.tiered_background()` is silently ignored

Cells: `AverageEffect` × CoDetermined (and Unknown).

`builder.rs:357-362` overwrites `self.graph` but leaves `self.tiered` set.
`matrix_graph_class` and the AverageEffect route key off `self.tiered` only
(`support.rs:386-389`, `dispatch.rs:546-560`). The caller's ADMG (for example
one with an extra T↔Y edge) is ignored, and the tier closure is certified.
The joint path does check `joint_adjustment_holds`; the single-treatment
closure (`tiered.rs:236-257`) does not.

Fix: return `CausalError::Conflict` when both are set independently, and add
the ADMG adjustment check to `identify_closure`.

### R-8 · P1 · epistemic — Bayesian PointDerivative / (Semi)Elasticity freeze nuisances and bandwidth, undisclosed

Cells: `PointDerivative`, `Elasticity`, `SemiElasticity` × Dag ×
{explicit, accepted} × Bayesian (6).

`response.rs:604-621` computes the cross-fitted pseudo-outcome and bandwidth
once, then reweights only the local-quadratic fit per draw. The Bayesian
limitations reuse the generic "weighted plugins" text. The Frequentist
diagnostic `response.derivative_interval_withheld` / "conditions on
bandwidth" is stripped (`response.rs:601-603`) without a replacement. By
contrast, `AverageDerivative` does refit its nuisances per draw.

Fix: refit per draw, or disclose the conditioning in both the limitations and
a diagnostic.

### R-9 · P1 · epistemic — Bayesian temporal conjugate likelihood assumes iid residuals, undisclosed on effect cells

Cells: Bayesian Pulse/Sustained × {TemporalDag, TemporalCpdag, TemporalPag}.

The NIG likelihood treats rows as independent. `temporal_sequential.rs:127-129`
notes the asymmetry with the Frequentist block bootstrap but makes no
coverage claim. The temporal response cells disclose the iid assumption
(`temporal_response.rs:183-195`, `temporal_observed_bayes.rs:725-749`); the
Pulse/Sustained limitations do not. Calibration DGPs are iid, so the gate
cannot see it (R-17).

Fix: disclose it now; measure it with an AR(1) DGP; and correct it (effective
sample size or a block Bayesian bootstrap) if coverage fails. Per the 1.9
rule, a known-miscalibrated interval gets fixed, not footnoted.

### R-11 · P1 · epistemic — Static graph-posterior Frequentist SE claim is false

Cells: `AverageEffect` and `ConditionalEffect` × Dag × graph_posterior ×
Frequentist (6).

The limitations say the SE "uses joint influence-function covariance on
shared rows." `execute_graph_posterior_frequentist` (`bayesian_path.rs:814-923`)

used by the PAG and class-conditional paths, but not here. The runtime output
is honest (NaN plus a diagnostic); the documented method is not what runs.
The diagnostic also fires unconditionally, including for a single atom
(`bayesian_path.rs:939`).

Fix: wire in the joint-IF combiner (see C-1 under calibration opportunities);
failing that, correct the text.

## C. The 1.9 calibration gate itself

These have to land before the 1.9 calibration items can be called done.

### R-14 · P0 for 1.9 · *verified* — The pass band cannot detect miscalibration

`v19_calibration.rs:36-45`: `N_SIM = 40`, band `level ± 4·se` floored at
0.70 and capped at 1.0. For nominal 90%, that accepts **[0.71, 1.00]**.

- A 72%-coverage interval passes.
- Over-coverage is never flagged.

`antecedent-estimate` uses `n_sim = 80`, which gives [0.766, 1.0]. The 1.9
TODO says that "a licensed cell whose intervals do not cover at the claimed
level … gets a fixed interval." At these settings the gate cannot find such a
cell.

Fix:

- Size `N_SIM` for a two-sided band of roughly ±3 percentage points: about
  400–800 replicates, with fewer bootstrap replicates per fit if runtime
  requires.
- Check both tails.
- Report Monte-Carlo SE and mean interval length alongside the pass/fail.

### R-15 · P1 — Multi-atom calibration DGPs are degenerate

| Fixture | Problem |
| --- | --- |
| `two_identified_dbn` (`v19_calibration.rs:207-223`) | Both atoms encode the same graph (adjacency `[0,0]`, lag masks `[2,2]`), so they give identical estimates and zero between-atom variance. |
| `known_truth_dbn_posterior`, `identified_plus_unidentified_dbn` | Only one atom ever contributes. |
| `xyz_cpdag` + `noisy_xyz` | z has no path to y, so both completions estimate the same 0.8. |
| `directed_pag` | No circle marks, so one completion. It is used by both "PAG envelope" tests. |
| `mediation_cpdag` | Fully directed, one completion (`total_masks() == 1`). |

As a result, no 1.9 coverage test exercises between-atom variance, cross-atom
covariance, class-prior weighting, or refuter targeting (R-3). A regression
that bootstraps atoms independently would pass.

Fix: add one heterogeneous fixture per structure: at least two identified
atoms with different true effects, plus nonzero unidentified mass. Calibrate
against `E[τ | identified]`. Also assert that the shared-block SE exceeds the
within-atom SE.

### R-16 · P1 · *verified* — Vacuous assertions in the gate

- `dbn_mixture_functional_retains_unidentified_mass` (`v19_calibration.rs:562-580`)
  asserts on `posterior.map_or(0.3, …)`. On the Frequentist path there is no
  posterior, so the check reduces to `0.3 == 0.3`. It is also OR-ed with
  `status == GraphDependent`.
- `class_prior_mixture_functional_nominal_90_coverage` asserts
  `unidentified_mass >= 0.0`.
- `bayesian_temporal_cpdag_mediation_envelope_nominal_90_coverage`
  (`v19_calibration.rs:534-550`) counts a replicate as covered if *any*
  completion's interval covers. That is not a property of the reported
  interval. The branch is dead today (R-15), but it would inflate coverage as
  soon as a real CPDAG is used.

### R-17 · P1 — Every calibration DGP is iid-Gaussian and correctly specified

There is no AR(1) generator, no short series (the minimum n is 160), no
nonlinearity or interaction for `bayesian.gcomp` (the static coverage test in
`bayesian_checks.rs:1587-1659` draws from the fitted model family), and no
non-Gaussian treatment law for the ADE. Block bootstraps (R-1), block-length choice, iid
conjugate likelihoods (R-9), and derivative bandwidth bias are therefore
never stressed.

Fix: add AR(1) at ρ ∈ {0.5, 0.9} and n ∈ {50, 160}. Add one misspecified
outcome for `bayesian.gcomp`, and a block-length sensitivity check at ×0.5,
×1, and ×2.

### R-18 · P2 — Coverage tests that bypass the staged path or cannot fail

- Bayesian single-step Pulse coverage (`bayesian.rs:2223-2296`) calls the
  estimator directly, bypassing `Study`/dispatch, so R-5 is invisible.
- The multi-step Sustained truth gives the second lag a zero effect
  (`noisy_xy`), so the composition across lags is never tested against a
  nonzero contribution.

## Resolution in 1.9.0

Every item above was implemented in the 1.9.0 cycle. The two-sided gate
(R-14) then found defects the review had missed, and two entries in
"Checked and correct" were wrong:

- **The f094d069 shared circular-block SE was not correct.** Rebuilding the
  lagged design from resampled raw rows pairs each outcome with regressors
  from an unrelated block at every junction and at the circular wrap. The SE
  was inflated 1.35–2.3× and every DBN and class-envelope interval
  over-covered (0.97–1.00). All temporal block bootstraps now resample
  blocks of lag-aligned rows, with a dependence-aware block length and a
  fixed-b correction.
- **The AIPW ATT/ATC standard error on the residualized branch was not
  correct.** It dropped the share term and projected the plug-in terms off
  the propensity scores; coverage was 0.980 (ATT) and 0.863 (ATC) at nominal
  95%. It now uses the centred efficient influence function.

Further defects found by calibration and fixed:

- Temporal mediation omitted mediator–outcome confounders from the
  adjustment set (mediated effect 0.519 against 0.300).
- Path-specific effects returned the total effect when a complementary
  directed path existed; they now use the edge g-formula.
- The linear-adjustment influence function centred the treatment instead of
  residualizing it on the adjustment set, understating envelope SEs by
  `sqrt(1 − R²(T | Z))`.
- ConditionalEffect SEs treated the modifier mean as fixed.
- Kennedy-DR response-curve bands omitted the outcome-model averaging term;
  penalized g-computation response levels were biased; the point-derivative
  interval ignored smoothing bias; the Bayesian Jacobian band was shrunk by
  the GAM penalty.
- Bayesian temporal credible intervals undercovered under autocorrelated
  residuals (0.44 at ρ = 0.9). The likelihood is now tempered by a long-run
  variance ratio.
- Observation-adjusted temporal bands resampled the raw series (0.45
  coverage); they now resample lag-aligned outcome-time tuples.
- The calibration harness seeded consecutive replicates identically.

Decisions taken where the review's framing did not survive contact with the
code:

- **Two interval semantics for mixtures.** Probability-weighted mixtures
  (graph posteriors, `ClassPrior`) publish the Bayesian model average over
  graph-specific effects, calibrated against the effect of a structure drawn
  from the weights. Enumeration-weighted envelopes (CPDAG/PAG) publish the
  posterior or SE of the frozen-weight aggregate, calibrated against that
  aggregate.
- **Temporal mediation CPDAG completions agree by construction.** Meek
  orientation and the treatment-induced-covariate refusal fix the adjustment
  set, so the multi-completion mediation fixture cannot make completions
  disagree.
- **Temporal response bands use a `max(span, ⌈√n⌉)` block**, the fixed-b
  testing rate, while scalar temporal effects use the dependence-aware rule.
- **Derivative intervals are centred on the bias-corrected slope** while the
  reported point stays the conventional estimate, flagged by
  `response.derivative_interval_bias_corrected`.
