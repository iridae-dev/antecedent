# 1.2 evidence and licensing limits

A matrix coordinate licenses the form in its limitations field, not every
likelihood, target population, policy or diagnostic under that query name.
Every added coordinate executes identification → prepare → estimate. Explicit
and accepted structures run the same numerical pins with their own structure
axis. There is no compatibility allowlist and no new external-package parity
claim. The [matrix](support-matrix.md) is authoritative.

## Independent posterior equations

[`release_12_moments/generate.py`](../conformance/bayesian/release_12_moments/generate.py)
imports NumPy only. It freezes Normal-inverse-gamma posterior means/covariances
at prior scales 0.1 and 10, including centered interactions, confounder-adjusted mediation, the variance of an
independent product, covariance when summing lag coefficients, and a repeated
stationary mechanism multiplying that sum. Python
[`test_release_12.py`](../python/tests/test_release_12.py) compares retained
posterior moments with tolerances scaled to Monte Carlo error. A strong-prior
posterior is not required to equal the DGP's structural truth; structural
fixtures separately check causal point targets. A small realized sample's
validation target is compared to its independently calculated posterior, not
misrepresented as a population truth.

## Artifacts and language boundaries

Actual prepared results are exported without refitting. Scalar posteriors retain
quantity names, draws, identification status, mixture mass and backend summaries;
they do **not** retain the complete analysis assumption or validation ledger.
Keep the analysis result alongside these existing-format posterior artifacts.
Mediation decomposition is checked draw by draw after decoding. Response
artifacts retain evaluated surfaces, intervals, support, identification and
response assumptions. Python → Rust → Python encoding is exactly checked;
`serde_json` float-roundtrip parsing prevents one-bit decimal conversion drift.
`export_artifact(payload="query")` also round-trips the canonical query from
actual prepared results across these families, including accepted functional
queries, conditional query kinds, pulse template variable IDs and signed sustained windows.
Python's primary mediation effect now reads the requested estimate contrast,
instead of overriding it with the decomposition's total.

## Provenance and interpretation

Eight new cards in [`provenance/`](../provenance/) record independent algorithms,
source exposure, implementation departures and executed evidence:
`validate.functional`, `validate.temporal_mediation`, `validate.dbn_posterior`,
`estimate.bayesian_conditional`, `estimate.bayesian_temporal_mediation`,
`estimate.response.bayesian`, `estimate.response.temporal.bayesian`, and
`estimate.temporal_sequential`. Gaussian regression uses the repository's tested
backends and standard [Bayesian regression equations](https://sites.stat.columbia.edu/gelman/book/).
Sequential composition uses the parametric g-formula described in
[Causal Inference: What If](https://www.hsph.harvard.edu/miguel-hernan/causal-inference-book/).
Citations motivate equations; they do not grant unimplemented theorem guarantees.

Refuter success proves neither exchangeability nor cross-world independence,
positivity or model correctness. Mean TV ≤ 0.1 is a declared descriptive
robustness threshold. Replicate comparisons have no new type-I calibration
claim. Binary mediator-range overlap is necessary empirical evidence, not
proof of conditional positivity. Gaussian posterior intervals assume the
specified conditional likelihood; no robustness to serially correlated
innovations or misspecification is claimed. Frequentist sustained uncertainty
uses shared circular moving blocks with a declared span-based block rule;
this is not a general coverage guarantee.

## Performance and boundaries

The existing temporal-response and temporal-mediation Criterion targets now
include 512-draw Bayesian paths. They assert bounded output shapes (no retained
row-by-draw expansion) and exercise prepared identification/design reuse. The
numerical paths use the existing dense backend and posterior workspace; no
new SIMD or parallel kernel is introduced. See [hot paths](hot_paths.md).

Graph-posterior response/path/distribution, multi-step DBN windows, nonlinear
mechanisms, Bayesian derivative responses and general static mediation remain
outside 1.2. Function-valued cheap/full is not applicable in either inference
mode. Prepared second-click `refute()` retains its AverageEffect-only contract;
set the new families' suite at preparation. New Python routed paths refuse
external prior transfer, custom validators and execution controls explicitly.

Composed mediation and multi-step sustained posteriors accept conjugate and
Laplace backends. HMC composition is explicitly refused until derived-contrast
chain diagnostics are staged; component convergence is not substituted for
convergence of a nonlinear composed quantity.

Continuous-treatment conditional validation uses a descriptive linear treatment-location
model on adjustment variables and the modifier. It reports the fraction of target
rows where both doses lie in the central empirical residual interval (default
5th–95th percentiles; default pass fraction 50%). This replaces binary propensity
fitting for continuous treatment; it does not prove conditional positivity.
Python prepared responses refuse non-complete observations, observation assumptions
and non-AllObserved populations instead of silently replacing them with defaults.

Full continuous-treatment validation also evaluates the stricter common-support
rule (default 10th–90th residual percentiles). The binary-ATE Riesz check reports
not-applicable for continuous treatment; the continuous support diagnostics,
PPC and prior sensitivity still execute. The shared-mechanism Gaussian sustained
coverage regression exercises both conjugate and Laplace backends.
