# Randomized-interference calibration

**Suite path:** `conformance/response/randomized_interference`

The two-unit Bernoulli design has four assignments, so both requested exposure
probabilities are exactly enumerable. The fixture then evaluates HT and Hájek
exposure contrasts and Antecedent's explicitly documented conservative Young
variance bound. The variance value is a repository contract, not a claim of
parity with Aronow–Samii's exact joint-exposure variance.
