# Choose an example

Each example asks one question and checks one property of the answer. Start with the tutorials: they are the maintained front door, and each pairs with a page that explains the science. Install [the matching package](start/installation.md), then run an example from a repository checkout.

```bash
python examples/python/<name>.py
cargo run -p antecedent --example <name>
```

Notebook previews show executed outputs; source downloads and Colab links are beside each notebook. See [the repository setup](https://github.com/iridae-dev/antecedent/blob/v3.0.0/examples/README.md#python-environment) for the local environment. For your own data, see [your first analysis](start/first-analysis.md); for a graph handoff to another library, see [DoWhy interoperability](interop_dowhy.md).

<!-- generated:example-catalog:begin -->

Examples run on simulated data with a declared mechanism, so the known truth can be asserted; a simulated truth is a fixture truth of that stated model, not a claim about a real system. One tutorial reads a real public dataset on request and falls back to a synthetic stand-in offline, and its output says which table it used. Runtime estimates assume a warm installed environment and exclude installation and Rust's first compilation. First native imports and notebook-kernel setup can add substantial time; machine, workload and optional dependencies affect elapsed time. Assertions check each example against its stated truth, not your causal assumptions.
