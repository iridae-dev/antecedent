# 2.0 learner audit — 2026-09-20

Scope: the in-progress learner substrate, faer integration, DML, DR-Learner,
causal forest, Python bindings, analysis identity, artifact transport, and
support/provenance/calibration contracts. Existing working-tree changes were
preserved. This is a review of the implementation and its evidence, not a claim
that every statistical configuration has been calibrated.

## Corrections

| Finding | Correction |
| --- | --- |
| PLR exported its unnormalized orthogonal score as an influence function. | Divide by the empirical residual-treatment second moment; derive the IID SE from that same influence. |
| PLR was called an ATE without stating its constant-effect restriction. | Record the restriction as a declared estimation assumption. Use binary-probability nuisance fitting for the currently supported binary treatment. |
| DR-Learner paired the mean fitted CATE with the SE of a different statistic. | Use the cross-fitted DR score for both the marginal ATE and its SE; keep CATE point predictions separate and center the influence. |
| Forest ATE uncertainty was calculated from variation between fitted CATEs. | Use cross-fitted ridge/logistic AIPW for the marginal ATE and its IID uncertainty. CATE heterogeneity is not sampling uncertainty. |
| Honest leaves could retain split-sample outcomes when their estimation sample lacked an arm. | Replace every leaf from estimation-only outcomes; use an honest ancestor estimate when available. |
| Auto selected nuisance learners before outer cross-fitting, using held-out outcomes. | Defer selection until each training-view fit; inner selection cannot read outer validation rows. |
| Trimming was described in diagnostics but ignored in DML/DR estimation. | Apply raw-propensity trimming to scores, preserve original-row influence alignment, and record retained sample size. |
| Analysis identity omitted learner hyperparameters. | Include all learner configuration fields, using exact floating-point bits, and correct the forest's default overlap identity. |
| Fitted learner identities were discarded; CATE predictions did not survive artifact transport. | Retain fitted model identities in results and Python views; serialize both identities and CATEs with backward-compatible defaults. |
| Fold identifiers could wrap, and malformed CSR input passed construction. | Validate index capacity, CSR origin, monotonicity, lengths, and column bounds. |
| Forust's global pool could exceed the execution budget; Burn's global RNG could be reseeded by concurrent fits. | Keep Forust calls serial within outer fold parallelism; serialize Burn training around its global RNG. |
| Forest split search allocated and rescanned partitions for every candidate, and sorted twice. | Use cumulative arm sums across sorted candidates and partition only the winning split. |
| Debug builds leaked the warnings module into the public Python API. | Use a private import alias; preserve the public-surface snapshot. |
| The calibration surface omitted the new learner crates. | Include both learner crates and their dependency manifests in the statistical surface. |

The forest remains a restrained honest leaf-contrast estimator for CATE; it is
not GRF inference. DR and forest CATE predictions do not carry pointwise
confidence intervals. The AIPW/PLR intervals require IID observations and the
usual nuisance-quality and overlap conditions; PLR additionally needs its
recorded effect restriction for the ATE interpretation.

## Evidence

The executing `learner_ate_known_truth_coverage` test consumes
`conformance/estimate/learner_ate/fixture.json`. It checks 200 independent
synthetic datasets, each with 600 rows, for each of four marginal estimators.
It tests interval coverage, bias, finite uncertainty, centered influence, and
agreement between exported influence and SE. This is a reproducible development
check for that particular linear/logistic binary-treatment SCM, not a committed
coverage attestation or evidence for other providers, sample sizes, CATE
intervals, or support-matrix coordinates.

The estimator inventory now cites this test and fixture with explicit limits.
No licensed support-matrix cells were removed or converted into refusals.
Additional regressions cover fold-local selection, honest leaves, trimming,
hyperparameter identity, CSR/index validation, and artifact round trips.
