# 2.0 audit: A–J and T0–T2

Scope: branch `2.0`, including the in-progress transport work present in the
working tree. Full empirical calibration is explicitly deferred at the user's
request. Ordinary known-truth regression tests do not attest calibrated coverage.

## Findings corrected

1. **Unjustified target intervention.** An empty source catalog previously
   produced `P_target(Y | do(A))` simply because no selection mechanism affected
   Y. Invariance does not identify an intervention in a confounded target.
   Target-only DAG queries now use the observational truncated factorization,
   including when selected mechanisms differ. Confounded queries without the
   required evidence no longer receive an invented experimental factor. Ancestor
   pruning avoids irrelevant measurement dependencies. Treatment mutilation also
   removes incident bidirected edges, as the graphical intervention requires.
2. **Lost catalog semantics.** Python identify and prepare previously forwarded
   only the union of experiment variables. Durable queries also omitted their
   catalog. Both native routes and `TransportQueryWire` now preserve it.
   Explicit catalogs distinguish exact intervention sets, measured joint laws,
   projections, available versus proposed evidence, assignments, and target
   sampling. Certified factors retain the chosen regime through expression and
   formula serialization. Legacy lists do not imply joint experiments.
3. **Insufficient catalog validation.** Unspecified first coordinates could
   mask incompatible later domains or units. Validation now refines that
   information and checks categorical cardinality, assignments, marginal
   membership, conditioning, duplicate bindings, and weight snapshot identity.
   Conditioning a collection of separate marginals does not create a joint law.
4. **Inconsistent expression scope.** Kernel parameters were removed from free
   variables even though evaluation used them. Kernels now preserve body
   dependencies and do not invent provider leaves. Substitution rejects
   conflicting mappings, coordinate collapse, and capture. Expectation binds
   its outcome coordinate. Symbolic intervention placeholders resolve from an
   assignment rather than passing NaN as a concrete intervention to providers.
   Their wire form uses an explicit symbolic marker, so JSON does not turn NaN
   into an unreadable null. The decoder validates table references and rejects
   cycles or duplicate entries that would remap expression identities.
5. **Incomplete derivation provenance.** Lowered expression steps now link to
   parent steps and retain evidence-regime dependencies; the root records the
   identification rule, graph operation, and checked premises. Python lowering
   attaches this metadata too. Derivation records now survive arena serialization;
   older artifacts without those optional records still decode.
6. **Discarded nuisance diagnostics.** DML and DR now expose held-out outcome
   R², treatment log loss, fold count, and master seed in Rust, Python, and both
   saved result forms. Their existing fitted learner provenance remains intact.
7. **Missing OOF reuse.** DML AIPW and DR share a one-entry cache on their prepared
   problem. It retains predictions, not fold models, and checks immutable input
   buffers, dimensions, learner specifications, folds, and seed before reuse.
   Changing an input buffer invalidates it. Already contiguous, unselected
   dense designs are now borrowed rather than copied by provider adapters.
8. **Incomplete stage licensing.** `parity/transport_stages.toml` records the
   identify and expression-reload contracts separately from the statistical
   analyze matrix. The support-matrix gate checks the stage registry and its
   collected test evidence. General identification/evaluation/uncertainty work
   belonging to T3 onward is not silently licensed by the T0–T2 types.

### Numerical arguments checked

For a causally sufficient target graph the target-only formula is
`sum_{V \ (Y ∪ A)} product_{Vi not in A} P_target(Vi | pa(Vi))`, evaluated at
A's requested level. This uses observational conditional factors; it does not
presume a target randomized experiment. Graphical invariance and supplied
measurement availability are separate obligations.

DML AIPW uses `m1(X)-m0(X) + T(Y-m1(X))/e(X)
- (1-T)(Y-m0(X))/(1-e(X))`. The reported ATE averages these held-out scores.
PLR divides its residual score by the empirical residual-treatment second
moment. Its constant-effect restriction is necessary for calling the Robinson
slope an ATE under heterogeneous treatment effects. DR's final CATE smoother
must not replace the orthogonal-score ATE or its influence function.

The transport theorem reference is Bareinboim and Pearl,
[A General Algorithm for Deciding Transportability of Experimental Results,
arXiv:1312.7485v1](https://arxiv.org/abs/1312.7485v1). The implemented subset does
not inherit the paper's completeness guarantee for arbitrary supplied catalogs.

### Provider copying boundary

The cross-fit executor uses row selections. Some backends require packed fold
buffers. Forust 0.5 bins the supplied matrix before using its training indices;
passing the full matrix with only a modified index would expose held-out
features to preprocessing. Fold packing remains intentional there. Borrowing a
contiguous full design is safe and now avoids the unnecessary copy. Replacing
this with an unsafe zero-copy claim would weaken the fold-isolation contract.
