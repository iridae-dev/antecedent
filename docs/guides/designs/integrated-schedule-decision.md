# Choose a two-decision schedule under joint uncertainty

The integrated schedule decision compares a finite class of static two-action schedules. A source study records a binary baseline marker, both assigned actions and an endpoint in ([0,1]). The endpoint is absent for a censored subject. A separate target sample records the same baseline marker. Each source row is one complete assignment trajectory, and each target row is one independent target subject.

Each declared structural alternative gives a way of interpreting the same source observations. In the first, both actions are causally effective and sequentially exchangeable given the baseline and previous action. Under a fixed schedule, the conditional utility outcome comes from its baseline-by-action cell. In the second, the first action remains exchangeable given baseline and the second has no causal effect. An unobserved post-first-action cause may influence the second action and endpoint. The procedure uses the natural second-action probabilities given baseline and the first action to average over that association. Both structures require consistency and positivity. In either structure, endpoint observation must be exchangeable conditional on baseline and both observed actions. Each structure's conditional schedule values must transport across the two populations.

The assignment, censoring and endpoint fits share the same source subjects. The target prevalence is learned from a separate sample. A preference state supplies a known cost for each schedule. For any fixed graph and preference state the target utility is the transported endpoint mean minus that state's cost. The target of inference is the union of the true maximizers over all declared graph and preference states, including every tied maximizer. The alternatives carry no probability weights.

## Joint procedure

The source fit uses eight observed-endpoint means and four natural second-action probabilities. The independent target contributes one baseline prevalence. Each of these thirteen ([0,1])-valued means receives a two-sided Hoeffding bound with error allowance (0.05/13). Source bounds condition on the relevant realized cell counts. A union bound controls their joint error without assuming independent source fits. The first-action and censor observation rates are diagnostics. The stratified conditional-mean procedure accounts for censoring under the stated premise through the observed endpoint count in each cell.

The program carries the same region through source evaluation, target standardization and decision. For a pair of schedules, the upper contrast bound uses common target weights. Under the first-action-only structure, comparison of schedules with the same first action cancels their common endpoint term. A schedule remains a compatible optimum when no simultaneous upper contrast bound places it below a competitor. Unioning over the declared worlds preserves every true optimum whenever the common region holds. The repeated-study probability of publishing a set that misses any true optimum is at most 0.05 under the premises. A sample that fails minimum overlap is refused. This is a bound on false publication over repeated studies, with no assertion conditional on passing the overlap filter.

Sampling uncertainty enters through independent source trajectories and target baseline rows. The confidence region bounds the sampled quantities. Structural alternatives and preference states are finite sets determined before sampling. The decision's calibration readout uses empirical evidence measured for the final optimum set under the two example designs, when those measurements are current. The analytic guarantee travels with the decision. The empirical status resolves from the reader's coverage registry. An empirical record requires an explicit declaration of its fixed study design. The two example design labels apply only to the Bernoulli study law in the coverage fixture, its exact schedule and preference worlds, and a target sample one third the size of the source sample. Other inputs retain their analytic coverage guarantee with an unmeasured empirical status.

## Run and replay

Use `antecedent.intervention_schedule_decision.compile_integrated_schedule_decision` with a sequence of `ScheduleSourceSubject`, the target baseline sequence and a `ScheduleDecisionDeclaration`. The compiled plan exposes distinct program identities for the joint source fit, independent target fit and fixed structural/preference worlds. Execute it with the desired `Execution` policy. `compile_schedule_decision_bundle` combines the two calls.

The result's `export()` supplies a typed composition artifact. Save its `expectation` independently before passing it as `expected_identity` to `consume_schedule_decision_bundle`. The reader recompiles each child and verifies its identity before replaying the optimum set. The Rust entry points are available in `antecedent::design`.

The conformance example in `crates/antecedent/tests/integrated_schedule_decision.rs` evaluates a rational eight-cell model with different source and target baseline weights. Its tied variant yields the exact oracle optimum set ({0,2,3}). The repeated studies resample independent source and target populations, refit assignment and censoring, and score the actual compiled decision on all true optima. An edited target changes the compiled identity. A stale terminal with the new target or without its target dependency refuses on replay.
