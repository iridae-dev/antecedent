# Documentation sources

These Markdown sources build the Antecedent 2.0 release-preparation site with
MkDocs. The published package remains 1.11.0 until the release cut.

Generated pages are `support-matrix.md` and `conformance/`; regenerate them
from their source registries before committing documentation changes. The
active draft release note is `release-notes/v2.0.0.md`.
