   (`python/src/cross_world_execution_api.rs`) still calls
   `FiniteScmExecutor::execute` on the retained executor. The retained-abduction

   It is not a compiled-path row. ADR 0030 names `analyze` as the call. The
   direct entries already deprecated for 4.0 stay wrappers.

three policy constructors in the same file are deprecated toward the cells

## Caller sketches

The choices are ADR 0030. The calls batches 2–6 implement:

```python
study = ant.prepare(
    data,
    query=query,
    inference=ant.Frequentist(),
    execution=ant.Execution(seed=1),
)
outcome = ant.estimate(study)
# one-shot, and the replacement for analyze_ate:
outcome = ant.analyze(data, query=query, inference=ant.Frequentist(), execution=ant.Execution(seed=1))
decision = contract.evaluate(joint_distribution)
recorded = ant.load(artifact, expected=outcome.expectation)
```

```rust
let study = StudyBuilder::new(/* ... */).learner_factories(factories).prepare()?;
let outcome = study.estimate(&execution)?;
let recorded = load(&bytes, expected)?;
```

A caller on `analyze_ate` or on `dml_ate` / `aipw_ate` / `dr_learner_ate` /
`causal_forest_ate` / `cross_fit_aipw` moves to `analyze` with `estimator`
set. A caller on `CrossWorldExecution::seal` moves to
`Study::compile_cross_world_execution`. A caller on
`CrossWorldExecutor.execute` stays on that method until 3a compiles it; the
refusal stays the executor's current refusal. A caller on
`transported_synthesis_response` or `surrogate_bridge_response` stays on that
function until 3a names its `route:` replacement. A caller reopening a sealed
claim uses `load`. A caller resuming a compiled study uses the format 0.6
open from batch 4, and passes the expected program identity separately from
the container digest.
