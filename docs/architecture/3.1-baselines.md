## Caller walkthroughs

A static average-effect study can supply a decision, a recorded claim, and a
portable estimator. For example, this study estimates an effect of two.

```python
import antecedent as ant
from antecedent.compiled_study import open_study
from antecedent.outcomes import require_success

data = {"a": [0., 0., 1., 1.], "y": [0., 0., 2., 2.]}
query = ant.AverageEffect("a", "y")
graph = [("a", "y")]
study = ant.prepare(data, graph=graph, query=query,
                    inference=ant.Frequentist(bootstrap=0), refute=False)
outcome = ant.estimate(study)
result = require_success(outcome)
artifact = outcome.export()
recorded = require_success(ant.load(artifact.data, expected=artifact.expectation))
assert recorded.claim_id == result.claim_id
saved = outcome.study.save_compiled_study()
resumed = open_study(saved.data, saved.expected_identity)
assert resumed.resumable and resumed.estimate == result.effect
```

An affine decision contract that reads this contrast uses
`require_success(contract.evaluate(result))`. A request for a quantile needs
a law. Read the refused outcome or call `require_success` to raise its typed
error. The equivalent Rust projection is
`antecedent::analysis::decision_result::apply_decision(&contract, &result, &schema, &ctx)?`.
For a portable Rust study, save with
`prepared.save_compiled_study(&result, &ctx, None)?` and reopen with
`antecedent::io::compiled_study::open(&saved.bytes, &saved.expected_identity, &|_| None, false)?`.
Both surfaces select the action with expected utility two on the four-row fixture.
[Python projection](../../python/tests/test_decision_result_projection.py) ·
[Rust study, decision and persistence](../../crates/antecedent/tests/ordinary_contract_compiled.rs)

To fit registered nuisance providers on a larger study, pass
`learners=Learners(outcome_provider, treatment_provider)` to either `prepare`
or `analyze`, importing `Learners` from `antecedent.external_learners`.
The default learner estimator is five-fold partially linear DML. With the same
table, graph, query and registered factories, the Rust declaration is

```rust
use antecedent::analysis::declared_learners::LearnerFactories;
use antecedent::estimate::{DmlAte, DmlScore};
use antecedent::prelude::{RefuteSuite, Study};

let factories = LearnerFactories::new(outcome_factory, treatment_factory, provider_identity)?;
let prepared = Study::tabular(data).graph(graph).query(query)
    .estimator(DmlAte::new().with_score(DmlScore::PartiallyLinear))
    .learner_factories(factories).refute(RefuteSuite::None)
    .build()?.prepare(&ctx)?;
let result = prepared.estimate_retained(&ctx)?;
```

| Earlier entry | Public call |
| --- | --- |
| `analyze_ate`, `dml_ate` | Use `analyze(..., learners=learners, estimator="dml")` for partially linear DML. The legacy default fits DML with an AIPW score. Use the compatibility entry `analyze_ate` to retain that exact estimator or its custom fold count and weights. |
| `aipw_ate`, `dr_learner_ate`, `causal_forest_ate` | Pass `estimator="aipw"`, `"dr_learner"` or `"causal_forest"` with `learners=` on the study. |
| `cross_fit_aipw` | For an effect and fold receipts use `analyze(..., learners=learners, estimator="aipw")`. The prediction-only wrapper takes a caller-supplied fold assignment. |
| Rust `CrossWorldExecution::seal` | `Study::compile_cross_world_execution((&request).into(), &ctx)?.seal(&ctx)?`. Python's `CrossWorldExecutor.execute(request)` compiles and retains abductions on its executor. |
| `surrogate_bridge_response` | `Study::compile_surrogate_bridge(&bridge, &claim, provider_id, &ctx)?.execute(&ctx)?` |
