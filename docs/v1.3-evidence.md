## Supported models

Point derivatives require an explicit positive finite bandwidth. Elasticities
require a positive treatment point and a positive fitted response at that point.
Average derivatives use the
implemented observed-law Gaussian-score Riesz representer only; the unconfounded
linear SCM fixture does not independently stress a Gaussian treatment density.
A second confounded SCM shows point and ADE recover the structural slope when
unadjusted Y~A does not. Directional responses and Jacobians use additive GAMs
with at most two treatments, a common adjustment set, and a shared complete-case
row set; the Jacobian is row-major and the supplied direction is not
renormalized. Differential missingness across outcomes is refused. Derivative
cheap/full remain n/a; no ATE refuters apply.

Static mediation uses the path-specific identifier, retaining recanting-witness
refusals, and linear additive structural equations with independent errors and no
treatment–mediator interactions. Declared mediators partition directed paths into
natural direct and indirect effects; unsupported empty path selections refuse.
Treatment-induced intermediate covariates omitted from the mediator list change
the selected path set rather than refusing.
Cheap uses placebo mediators (target: indirect effect) and random common cause
(target: requested contrast), plus mediator-range overlap diagnostics for binary treatments.
Full also uses an 80% random subset, honoring its analysis mask. Bootstrap
uncertainty, when requested, jointly resamples static rows and refits equations.
A confounded SCM pins the same structural contrasts when unadjusted parent
regressions omit Z.

Counterfactuals are single-treatment, single-outcome two-world unit ITEs
`Y(a)−Y(a0)` under fitted GCM mechanisms and abducted disturbances, not a
factual-versus-counterfactual residual. The estimator id is `gcm.fit`. Each
prepared estimate refits mechanisms against the supplied data. The confounded
SCM additionally pins mean ITE when unadjusted Y~A does not recover it.
Mechanism assignments and observed treatment range are reported. Sampling
uncertainty is unavailable. Identification is parametric (`gcm.parametric`).
Control lives on the query (default hard set of the treatment to zero), matching
Python `control_level`. Result artifacts preserve those levels, per-unit
effects, their mean, identification, assumptions and support diagnostics.

The [observation pair contract](observation-contract.md) specifies censoring and
selection restrictions. Nested/temporal/accepted counterfactuals, weighted Riesz,
PAG derivatives and Bayesian versions of these new families remain refused.
Transport and interference remain separate stage APIs. General sID and Riesz
sensitivity remain 2.0 work.

## Verification

The release runs the R oracle, targeted Rust/Python numerical and artifact tests,
workspace formatting, clippy and tests, Python lint/type/tests with coverage,
and `scripts/gate_release.sh`. The release gate includes the new response
conformance and prepared-handle benchmark smoke.

Local verification on 2026-09-08: the rebuilt Python extension passed 1,082 tests
with 85.29% coverage (85% required). Python lint, formatting and mypy passed;
Rust workspace clippy passed with warnings denied, and all 1,706 workspace
tests passed. The two prepared-handle
benchmarks have measured [local baselines](https://github.com/iridae-dev/antecedent/blob/main/benches/baselines/staged_handle.md).

The complete release gate passed, including all prior feature gates, causal
artifact checks, generated-document checks, designated Criterion smokes and
`cargo deny check` (advisories, bans, licenses and sources). The advisory check
required access to Cargo's cache outside the workspace; the final gate ran
end to end with that access. No prior gate or dependency check was skipped.
