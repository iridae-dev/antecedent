## Corrections

1. **Functional posterior coherence.** Independent draws for overlapping CPTs
   and interventional aliases did not describe one observational distribution.
   The evaluator now derives every factor from a shared Dirichlet row-law
   draw on one common complete-case sample. This preserves the chain rule, reuses identical kernels, and retains
   zero mass on unobserved joint cells. Distribution atoms retain deterministic
   ordering. The empirical-support prior is recorded among result assumptions.

2. **Extra resampling variance.** Derivative and counterfactual implementations
   drew Dirichlet weights and then sampled another data set of the original
   size. That second sample adds uncertainty and is not direct Bayesian
   bootstrap evaluation. Weighted local-polynomial, GAM, Gaussian mechanism,
   and multinomial fits now consume continuous weights directly. Shared
   numerical kernels serve both weighted and unweighted paths.

   ADE refits the additive-GAM outcome and Gaussian treatment law under
   those weights each draw (not a frozen-score reweight). Point derivatives
   condition on fitted cross-fitted nuisances and bandwidth;
   GAM derivatives condition on knots and the smoothing penalty. Counterfactual
   fits condition on the selected mechanism families and repeat abduction on
   the original units for every draw. These restrictions appear in diagnostics
   and assumptions. The implementation follows the row-weight construction in
   [Rubin (1981)](https://people.eecs.berkeley.edu/~jordan/sail/readings/rubin.pdf).

3. **Mediation composition.** Requests for fewer than two draws are a typed
   refuse at the Bayesian config / execute boundary (no silent rewrite of 0
   or 1). Independent per-mechanism adaptive stopping is disabled during
   composition. EffectFunctional transfer maps ATE/Δ onto the
   outcome-mechanism treatment slope only.

4. **Prior and result honesty.** Functional and derivative paths no longer
   silently discard explicit coefficient priors for incompatible
   parameterizations. This does not remove any base query/inference cell.
   Response-transfer preparation includes every intervention coordinate.
   Bayesian derivative intervals no longer carry a contradictory frequentist
   “interval withheld” warning. Derivative assumptions retain the underlying
   estimator's nuisance restrictions.

5. **Builder and release consistency.** Switching the inference setter back to
   Frequentist clears its automatically selected Bayesian estimator, while
   explicit estimator configuration remains authoritative. Stale tests that
   expected 1.8 features to be closed now check the licensed boundary and actual
   graph identification. Current-version documentation is synchronized with
   the workspace. Python stubs cover the new prior arguments; fixture reads
   explicitly use UTF-8. Abandoned derivative helpers were removed.

## Follow-up review

The follow-up found and corrected five remaining boundary defects:

1. **Distribution posterior completeness and coherence.** Bayesian distribution
   execution required a finite scalar mean, so valid joint outcome and full
   conditional tables failed. It also paired empirical plug-in atoms with a
   different posterior mean. Every final probability atom now has a posterior
   draw column; published probabilities are their means. A scalar effect column
   is present only when defined. Each draw remains a normalized conditional
   law, and averaging those laws preserves normalization and agrees with the
   scalar mean. This corrects the earlier claim that averaging final cells
   would be Jensen-incoherent: the nonlinear functional is evaluated before
   averaging. The shared observational-law construction remains unchanged.
   Python preserves missing scalar summaries while exporting atom draws and
   displaying the posterior as computed.
2. **Mediation mappings across mechanisms.** A named mapping with targets in
   different regressions previously failed on each regression's absent targets.
   Each mechanism now binds its local subset; a target absent from all fitted
   mechanisms is still reported. The composed posterior preserves the actual
   coefficient/residual prior assumptions with mechanism variable scopes, and
   named mappings are no longer described as ATE mappings.
3. **Graph mixture assumptions.** Static Bayesian class and DAG-posterior
   envelopes now retain component priors and estimation restrictions, labeled
   by graph atom. The frequentist envelope diagnostic explicitly identifies its
   reported mean as conditional on identification.
4. **Explicit estimator configuration.** Query setters and functional dispatch
   previously rewrote an explicitly selected `bayesian.gcomp`. Only automatic
   defaults now adapt to query type; explicit incompatible selections report
   the existing compile error in either setter order.

5. **Python posterior metadata.** The full Python suite exposed a missing bridge
   for the new source-contrast field: summary-only artifacts could not declare
   it, and decode/encode discarded it. `PosteriorArtifact` constructors now
   accept `treatment_contrast`, decoded artifacts expose and retain it, and
   round trips preserve the full quantity schema (roles, coefficient indices,
   and names) instead of reconstructing it from names. Regressions cover
   summary-only hydration and positive/negative non-unit contrasts through both
   identical-coefficient and effect-functional mappings.

No licensed cell was removed. Distribution tests now exercise the previously
missing joint/conditional behavior at all licensed validation levels.
