# 1.2.0 — Compatible estimators and query-native validation

Implemented on the `1.2.0` branch. This minor release adds 38 licensed
coordinates using existing query kinds and graph classes. The authoritative
[support matrix](../support-matrix.md) records the supported forms; the
[evidence ledger](../v1.2-evidence.md) links numerical references,
provenance, artifact checks and limitations.

## What changed

- Path-specific and interventional-distribution queries now support explicit
  and accepted DAGs with native cheap/full validation. Subsets refit the actual
  functional; distributions compare whole probability tables. Their discrete
  evaluator now honors analysis masks.
- Temporal mediation has mediator-placebo, random-common-cause and applicable
  binary mediator-support checks; full adds contiguous-window stability.
- Bayesian conditional and temporal-mediation estimators fit actual posterior
  mechanisms. Mediation retains direct/mediated/total decomposition per draw.
  Native validation includes PPC and full prior-sensitivity refits.
- DBN posterior pulse/single-step sustained queries run applicable mixture
  effect validation, contributing-atom PPC and full prior sensitivity, while
  preserving unidentified graph mass.
- Static and temporal Bayesian responses use separate Gaussian response
  estimators with pointwise posterior intervals and empirical support records.
- Multi-step sustained queries use sequential g-computation on an identified
  unfolded DAG, intervening at every treatment time. Frequentist uncertainty
  uses shared moving blocks; Bayesian uncertainty composes Gaussian mechanisms.
- Python exposes `SustainedEffect(..., window=(-2, -1))` and
  `PreparedAnalysis.export_artifact()`. JSON artifact crossings now preserve
  exact floating-point values. No artifact format change is required.

## Evidence

The eight new provenance cards and parity entries specify model restrictions
and implementation departures. Rust staged tests compare against structural
DGP truths and existing independent references. A NumPy-only equation fixture
pins posterior means and variances under weak and strong priors, including
interaction, mediation-product and sustained-coefficient covariance terms.
Python tests export actual results and verify numerical and schema round trips.
Representative Bayesian response and mediation benchmarks extend the existing
hot-path targets. These checks make no new external-package parity or general
interval-calibration claim.

## Explicit refusals

The zero-cell root queries remain `AverageDerivative`, `DirectionalDerivative`,
`PointDerivative`, `ResponseJacobian`, `Elasticity`, `SemiElasticity`,
`Counterfactual` and `MediationEffect`. Their lower-level primitives do not
constitute a licensed staged root-query analysis.

Bayesian additions are restricted to the documented Gaussian linear forms,
complete observations and fixed AllObserved empirical populations. Response
intervals are pointwise; function-valued cheap/full remains not applicable.
Multi-step sustained accepts validation none, explicit/accepted TemporalDag,
and no discovery-estimation split. Nonlinear mechanisms, multi-step response
surfaces, graph-posterior response/path/distribution and multi-step DBN windows
remain refused. The new Python routed paths refuse external prior transfer,
custom validators and execution controls rather than dropping options.
Composed mediation and multi-step sustained HMC are refused until diagnostics
for the derived contrasts are staged; conjugate and Laplace remain supported.

The existing posterior artifact retains draws, quantity names, identification,
mixture mass and backend summaries; it does not contain the complete assumption
or validation ledger. Retain the analysis result alongside it. Response
artifacts include their response-specific assumptions and support.
