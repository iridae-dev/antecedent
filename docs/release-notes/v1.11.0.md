# Antecedent 1.11.0

The 1.x close-out on the 1.10.0 composition contract. 1.10.0 remains the
closed composition baseline. This cut opens additional licensed cells and
identification surface, and carries the P speed program. It does not start
the 2.0 transport program.

## What 1.11.0 claims

- The 1.10 inspect → preview → execute → claim → consume path remains the
  compiler lifecycle for every licensed cell.
- Ordinary one-call analyses retain reusable studies.
- The default user path uses the machine (`threads>1`); `for_tests` stays
  serial and scalar. User-sized benches live in this tree. Graph-posterior
  atoms and bootstrap replicate evaluation share one `ctx.parallelism`
  budget. `result.refresh` is the five-line second click.
- External estimator handoffs keep identification Antecedent-certified and
  estimation caller-attested.

Every Antecedent analysis retains a reusable study and exports a contracted execution; custom validator results travel as caller-attested, not re-verifiable, evidence, and a row-weight retarget re-executes only on its own data snapshot.

Every reported interval states its calibration: calibrated when a coverage record matches the execution and the execution is inside that record's scope; scope_not_assessed when a record matches but the execution is outside its scope or the record is a boundary; unavailable with a reason code when no record exists.

Identities are distinct and stable: every IdentityDomain plus target_weights is domain-separated and registered in parity/identity.toml.

## Pre-calibration review corrections

- Class and ADMG graph-posterior aggregates no longer expose the highest-weight
  atom's posterior as the aggregate posterior. A top-level posterior is retained
  only for one fully covered atom with one completion; available conditional
  posteriors stay attached to their own atoms. Other aggregate posteriors are
  withheld with an explicit diagnostic.
- Bayesian temporal class mediation now returns the accumulated weighted
  completion mean instead of the first completion's mean. It does not attach
  that first completion's uncertainty to the weighted mean.
- Capped class-posterior searches report `full_mass_scope = false`. Capped or
  unevaluable class-posterior results do not claim full-target point
  identification; class response payloads also withhold full-target uncertainty.

These are numerical and reporting corrections, not calibration evidence.
Calibration must be rerun against the corrected implementation before making
coverage claims for this release.

A [broader mathematical re-review](../reviews/v1.10.1-math-rereview.md) also
corrected relative-weight overflow/underflow, scale-dependent retarget checks,
column-order-dependent contrasts, and intervals that silently discarded missing
completion estimates or converted invalid variance to zero uncertainty. These
changes also require calibration against the corrected implementation.
