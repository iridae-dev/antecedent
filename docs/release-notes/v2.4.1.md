# Antecedent 2.4.1

Changes since 2.4.0. This release extends the existing workflows for interventions, fitted mechanisms, discovery, transport and weighted studies. The sections below describe implemented behavior. Calibration of several new interval constructions is still pending; this draft does not promote them to measured claims. The generated claim blocks reflect the current registry and will be refreshed after formal evidence is collected.

The weighted discovery-to-effect procedure also has a distinct three-quarter discovery allocation. It resolves orientation conflicts only when compatible resolutions preserve the treatment parent set. Its original half-split replay and records remain separate, and the new construction still needs its own formal calibration.

## Consumer workflows

| If you need to… | What 2.4.1 adds | Scope and evidence |
| --- | --- | --- |
| Express an intervention as a policy | [Typed intervention programs](../guides/intervention-programs.md) with arithmetic, conditions, clipping and variable or history reads; one execution path for sampling, counterfactuals and rollouts | Simulation, counterfactual execution and observational identification have separate licenses. Programs validate dependencies and output types. |
| Choose and validate fitted mechanisms | [Boosted and forest mechanism families](../guides/mechanism-selection.md), per-node candidates and constraints, and shuffled, ordered or clustered validation splits | The result records the selected mechanism and validation provenance. A fit is not a causal identification claim. |
| Check a proposed graph against observations | [Graph falsification](../guides/graph-falsification.md) tests local Markov implications against node relabellings | Reports rejection, non-rejection, insufficient information or incomplete computation with its test and budgets. Non-rejection does not establish the graph. |
| Replay noise or attribute variation to it | [Noise replay](../guides/noise-replay.md) and [intrinsic causal influence](../guides/intrinsic-influence.md) reuse the compiled mechanisms | Permutation, simulation and mechanism-fit uncertainty remain distinct. |
| Analyze incomplete or unequally sampled observations | [Missing-data policies](../guides/missing-data.md) and [sampling weights](../guides/sampling-weights.md) across additional estimators | Weighted intervals have their own population target, variance construction and calibration coordinate. Unweighted evidence is not inherited. |
| Estimate an effect after discovery | Treatment-parent-set adjustment accepts unresolved edges away from the treatment; the versioned procedure allocates three quarters of rows to discovery and one quarter to independent analysis | Retains the original generating families, reporting and width requirements. Its own coverage records and versioned replay determine attestation; it makes no per-dataset graph-recovery guarantee. |
| Transport through an uncertain discovered structure | [PAG and temporal class transport](../guides/discovered-structure-transport.md) uses the experiments actually supplied, checked minimal standardization and temporal block bootstrap | An explicit completely randomized binary-trial compatibility test can refine the static class, recording every exclusion and its evidence. Disagreement remains a structural range; unsupported members remain a refusal. New complete-procedure calibration is pending. |
| Pool independent Gaussian study estimates with unequal unknown variances | `EvidenceLedgerSession.pool_gaussian_studies` uses an equal-study mean and empirical study-level variance with a declared Student reference | This is a distinct construction for a common marginal study mean. Its conservative coverage role and measured scope require their own evidence; the released inverse-variance and HKSJ routes remain distinct. |
| Work beyond previous size ceilings | Wider graph posteriors, budgeted graph searches, larger matching and sensitivity problems, and participant-scale adaptive trials | Explicit resource budgets and completion diagnostics replace several fixed ceilings. Larger inputs do not widen scientific claims. |
| Control posterior endpoint accuracy | Optional minimum draw counts and endpoint Monte Carlo tolerances, with draws and seed retained for replay | An inadequate requested draw budget or endpoint precision is disclosed or refused rather than silently presented as a calibrated interval. |

## Interval methods and calibration

Responder-weighted variance now accounts for estimated response probabilities. Weighted population routes distinguish positive calibrated IPW weights, model-assisted outcome-noise calculations, regression-adjusted propensity strata and the published finite-cluster reference. Matching corrections account for shared outcome fits and the correct donor arm. These methods retain the original population targets and require records for the interval actually returned.

The calibration runner preserves earlier collected evidence and its original decision semantics. New coverage-compatibility decisions account for the complete declared family and planned replicate looks, using a seed domain frozen before validation outcomes are observed. This controls false coverage-compatibility rejections for that frozen validation batch; it does not prove exact nominal coverage or replace reporting, width, minimum-replicate or scientific coverage-floor requirements. Development probes are not collected evidence, and method changes are not waived when they change numerical results.

## Compatibility

The released Rust paths and signatures remain available. New optional fields require constructors, builders or `..Default::default()` when callers build public structs directly; see the [changelog](../../CHANGELOG.md#241). Released artifact formats and identities remain available, while new method versions and explicitly requested construction options carry their own identities. Parent-set sources retain a replay path for the earlier half-split procedure. A record for one method version does not attest another.

This draft remains pending until the new measurements, promotion and licensing updates, attestation waivers, generated inventories and release gates agree. No release snapshot has been frozen for 2.4.1.

## How to read the claims

| Term | Meaning |
| --- | --- |
| `point_only` | An exact or plug-in point estimate. No interval of any kind is claimed. |
| `nominal` | An interval whose coverage was never measured at its own coordinate (`estimator_grid_not_measured`). Cells publish none. |
| `calibrated` | An interval with a coverage record measured at its own coordinate; shown to readers as a *statistical interval*. A cell is described this way only once its records exist. |
| `structural_envelope` | The range of an answer over explicitly supplied structural scenarios. Not a confidence interval. |
| `assumption_range` | The range of an answer over a declared sensitivity set. Not a confidence interval. |
| `none` | No numerical claim: identification or inspection only. |
| statistical interval | The reader-facing name of a `calibrated` interval; it appears only beside a measured coverage record. |
