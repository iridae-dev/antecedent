# Antecedent 0.4.0

Both API surfaces — Rust and Python — reached the shape they will keep into 1.0, and the
algorithmic core went through a systematic correctness audit that changed real numbers in
twenty-five places.

If you are new here, start with the [notebooks](https://github.com/iridae-dev/antecedent#try-it).
If you are upgrading from 0.3.x, read the [breaking changes](#breaking-changes) — this
release renames a lot, deliberately, and there are no shims.

## Why the correctness work matters

Causal inference libraries fail quietly. A wrong answer looks exactly like a right one: a
number, an interval, a green diagnostic. So the audit went looking specifically for places
where Antecedent could return something plausible and wrong without saying so — and it
found some. All twenty-five are fixed, each with a regression test that was checked to fail
against the previous code.

Four of them are worth naming, because they are the shape of thing that erodes trust in a
result you cannot independently check.

**An identification verdict could be unearned.** Path enumeration silently truncated at a
budget, and the recanting-witness test concludes an effect *is* identifiable from the
*absence* of a witness. A witness on a dropped path was invisible, so a path-specific
effect could come back `NonparametricallyIdentified` when Avin–Shpitser–Pearl says it is
not. The enumeration now reports truncation and identification fails closed. Separately,
generalized adjustment over a PAG examined a deterministic 32-completion prefix of the
equivalence class — 32 of 729 on a 7-node chain — and reported zero unidentified mass, as
though it had checked all of them. It now says when the class is larger and refuses to
claim a class-wide property from a prefix.

**A sampler that never moved reported perfect convergence.** When a graph-MCMC chain
accepts no structural move, every edge trace is identical, and identical traces produce
R̂ = 1.0 and ESS = n_chains × n_draws — flawless numbers that mean *nothing varied*. The one
diagnostic that separates those cases, `all_chains_moved`, was computed, stored, and never
read. It is now part of the publication gate.

**p-values drifted at scale.** The incomplete-gamma series behind G² capped its iterations
at a fixed 500 with no convergence check. Past about 10⁴ degrees of freedom — reachable with
modest cardinality and a few conditioning variables — it returned a partial sum as truth:
0.739 where SciPy gives 0.500 at df = 10⁶. Since p-values feed BH/BY correction and edge
ranking, that distortion propagates. The iteration budget now scales as O(√a).

**Binary variables were modelled as their own mean.** Mechanism selection scored families
on conditional-mean fit, where a point mass is unbeatable — it predicts the mean exactly.
So `Constant` won for every parentless node and every binary column, and sampling a binary
treatment returned 0.5, a value it never takes. Roots carried no distribution at all, which
in turn made input-distribution attribution structurally impossible. Selection now tests
the claim `Constant` actually makes: that the variable is deterministic.

The rest span temporal discovery (LPCMCI convergence, PCMCI+ conditioning priority, RPCMCI
regime fitting, lagged constraint enforcement), estimation and validation (sensitivity
analysis calibrated against the wrong variance, propensity caliper scale, NOTEARS
sparsity), and diagnostics that were mislabelled or unreported. The
[CHANGELOG](../../CHANGELOG.md) has the complete list with the measured before-and-after
for each.

## Statistics that now say what they mean

Several quantities were correct-looking but misnamed, which is its own kind of wrong.

- **Anomaly scores** were a negative log *density*, reported as an information-theoretic
  score. A density is not a probability: it carries units, it is unbounded, and it moves
  when you rescale the target. Multiplying an outcome by 100 shifted every score by exactly
  `ln(100)` while nothing about the data changed. Scores are now tail probabilities.
- **Arrow strength** was `|β|`, which says nothing about how much the parent varies — it
  ranked a parent that barely moves above one that dominates. It is now `β²·Var(parent)`,
  the variance the edge actually contributes.
- **Mechanism-change detection** compared each target against the nominal α with no
  correction across the family, giving a ~40% family-wise false-positive rate at ten
  targets. It now applies Benjamini–Hochberg by default and reports the raw and adjusted
  p-values separately, rather than one silently overwriting the other.
- **Effective sample size** was floored and clamped in ways Stan and ArviZ are not,
  understating well-mixed chains; the GAM effective-degrees-of-freedom double-counted the
  constant, one per smooth term.

## New checks

Coverage machinery that existed but was never invoked is now wired into the scheduled
calibration gate: simulation-based calibration and posterior interval coverage for the
Bayesian path, and a coverage test for the sharp-RD analytic standard error — the only
estimator with an analytic SE that had none. Posterior predictive checks gained a
dispersion axis, so a model with the right mean and five-times-wrong variance no longer
passes. Conditional sampling refuses soft and stochastic overrides on a conditioning node
instead of returning a quietly biased estimate, and four conditional-independence tests now
reject a block-preserving request they could not honour rather than silently permuting
exchangeably.

## Breaking changes

Both surfaces were restructured. Neither has shims: if a name is missing, it moved, and the
[CHANGELOG](../../CHANGELOG.md) is the migration document.

### Rust

The facade now makes the analysis stages explicit in the type system rather than in
convention.

- **`CausalAnalysis` is `Study`** — construct with `Study::tabular(data)` or `::series` /
  `::series_multi` / `::panel` / `::events`. `StudyBuilder` and `StudyResult` follow.
- **The discovery-to-estimation path is staged behind `AcceptedGraph`.** A discovered graph
  has to be *accepted* before estimation will run on it, which is the type-level expression
  of the rule that discovered structure is evidence rather than ground truth. This replaced
  `GraphInput`, `CompiledAnalysis`, `DiscoveryAccept`, the `StudyBuilder::discover_*`
  methods, and the `finish_*_review_and_run` continuations — all removed.
- **`identify()` no longer needs data.** Identification is a question about a graph and a
  query, so you can now ask it before you have a dataset.
- **Estimators carry their configuration.** `EstimatorSpec` plus `with_*` setters on every
  estimator config, instead of threading options through call sites.
- **`IdentifierId` and `EstimatorId` are closed.** The `Other(Arc<str>)` escape hatch is
  gone; an unrecognised identifier or estimator name is rejected at parse time rather than
  deferring the failure to first use. This reaches Python too — a bad `identifier=` or
  `estimator=` string now raises immediately.
- **One error hierarchy across the workspace** (`CausalError`), replacing per-crate error
  types. The `AnalysisError` alias is removed.
- **Graph codecs preserve variable names** through a round-trip in every format (DOT, JSON,
  GML, NetworkX); earlier versions discarded them. `EdgeEvidence.separating_sets` is now
  `separating_set`.

### Python

The root namespace is frozen at 41 names, down from 206, organised around three verbs —
`analyze`, `identify`, `estimate` — with everything else on stage modules
(`antecedent.discovery`, `antecedent.priors`, `antecedent.attribution`, …).

[`docs/api_naming.md`](../api_naming.md) has the complete mapping and the rule for where any
given name lives. The short version:

```python
# before                                    # after
antecedent.discover_pc(data, alpha=0.05)    antecedent.discovery.PC(alpha=0.05).run(data, seed=1)
antecedent.dag_from_dot(text)               antecedent.Dag.from_dot(text)
antecedent.target_all()                     antecedent.population.target_all()
analyze(..., refute=True)                   analyze(..., refute="placebo")
```

Queries are keyword-only after their identifier prefix, `refute=True` is now a `TypeError`
(name the suite: `"placebo"` / `"cheap"` / `"full"`), `prior_bank` is `priors`, and
`identify()` at the root returns a staged `Identification` you can `.estimate(data)` or
`.validate(data)`. Python is unaffected by the `Study` rename — the PyO3 class name was
deliberately left alone.

### Behaviour

Three changes are worth knowing about even though they are corrections rather
than API changes. Binary and parentless variables now get real distributions instead of
point masses, which changes counterfactual abduction to posterior-noise mode on any model
with a discrete node. The propensity caliper is now interpreted on the logit scale, which is
what the 0.2 rule of thumb from Rosenbaum–Rubin and Austin actually means. And anomaly
scores and arrow strengths are on new scales — rankings are more trustworthy, but absolute
values are not comparable to 0.3.x.

## How this is verified

Antecedent treats traceability and behavioural verification as merge requirements, not
release-time aspirations. Concretely, for 0.4.0:

| | |
|---|---|
| Rust tests | 1323 |
| Python tests | 503 |
| Coverage floor | 85%, enforced in CI |
| Conformance fixtures | 130 documented pages |
| Platforms | CPython 3.11–3.14 on Linux, macOS, Windows |

Every significant algorithm cites its scientific sources and records which upstream
implementations were consulted, in [`provenance/`](../../provenance/). Implementations are
output-verified on pinned fixtures against DoWhy, scikit-learn, and Tigramite where
applicable, with no unexplained divergence permitted, in
[`conformance/`](../../conformance/). Public behaviour is held in parity across the Rust and
Python APIs, in [`parity/`](../../parity/). A scheduled gate runs the statistical checks
that are too slow for every commit: Type-I error rates, confidence-interval coverage,
p-value uniformity, and discovery false-positive rates. CodeQL and `cargo-deny` run on every
push.

These establish algorithmic lineage, agreement on defined reference cases, and consistent
cross-language behaviour. They do not validate your causal assumptions, and no result here
implies endorsement by the referenced projects.

## Install

```bash
pip install antecedent        # CPython 3.11–3.14, Linux/macOS/Windows
cargo add antecedent          # Rust 1.85+
```

Wheels are attached to this release and published to PyPI; crates are on crates.io. The
`docs.tar.gz` asset contains the narrative docs, the Rust API reference, and the Python API
reference for this exact version.
