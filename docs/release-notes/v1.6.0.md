# Antecedent 1.6.0

Implemented on the `1.6.0` branch. Temporal policy surface: per-horizon
identification, licensed Sequence overlays, and DBN-posterior mixtures on the
queries the handle already runs. The [support matrix](../support-matrix.md)
is the license.

## What changed

- `TemporalMediationEffect` uses horizon-specific `I(h)`. Estimate clicks
  reuse that horizon's unfolded backdoor, not a union adjustment set.
  One horizon preserves the scalar fields; multiple horizons return every
  slice in `mediation_grid`, with pointwise uncertainty and no claimed joint
  posterior.
- Multi-step and joint `Sequence` overlays run on sequential g-computation.
  Additive shifts preserve the intervened node's parent mechanism. Nested
  Sequence stays refused rather than collapsing to the last step. Joint
  longitudinal support remains unassessed and is marked extrapolative.
  Bayesian Sequence bands use per-horizon posterior equal-tail quantiles.
  Soft `multiplicative` scales the structural assignment by its factor.
  `truncated_shift` targets a bounded population mean by replacing `f` with
  `f + clip(mu + delta, lower, upper) - mu`, where `mu = E[f]` under preceding
  interventions. Parent effects and innovations remain; realized outcomes are
  not clipped. Both compose across joint and multi-step schedules.
- DBN-posterior Bayesian `TemporalMediationEffect` mixes per-atom `I(h)`.
  Each horizon retains its own certifiability flags and unidentified mass,
  including wholly unidentified slices. Priors do not upgrade ID.
- DBN-posterior multi-step `SustainedEffect` supports none/cheap/full in both
  inference modes. Placebo, nuisance-covariate, subset, bootstrap, and unobserved
  confounder checks refit the full sequential model per atom. Bootstrap checks
  preserve temporal blocks. Bayesian checks use the fitted stationary mechanisms
  for PPC and refit the composed effect at every prior-scale grid point.
  Single-regression sensitivity formulas are explicitly inapplicable to this
  composed effect; unobserved-confounder perturbations remain available.
  Explicit temporal DAGs use the same validation path.
- Pulse and single-step Sustained remain the contrast envelope.
- Licensed 1.3 observation pairs ride Frequentist temporal
  `ResponseCurve` / `InterventionResponse`. `IndependentGiven(Z)` lag-aligns
  Z at the policy offset.   Requested uncertainty uses an outer circular-block
  bootstrap that refits observation nuisances and all horizon models,
  including Sequence overlays. Bands are withheld when fewer than two
  replicates succeed or more than half of attempted replicates fail; counts
  and cancellation remain visible.
  Unlicensed non-`Complete` refuses at compile.
- Bayesian graph-mixture effects use categorical model draws followed by
  within-model posterior draws. Mean and variance are the exact
  identified-conditional functionals of the supplied empirical component
  posteriors, up to floating-point error. Quantiles use finite Monte Carlo
  draws from a fixed reproducible stream; atom order is invariant;
  unidentified mass is not normalized away.
- Static DAG graph-posterior responses retain probability-weighted atoms and
  mass. CPDAG/PAG completion responses retain enumeration atoms and identified
  sets; completion count is not posterior probability.
- Frequentist DBN Pulse/Sustained mixtures use fixed graph weights and shared
  circular-block replicates across all atoms.
- Frequentist `TemporalCpdag` / `TemporalPag` response surfaces retain
  per-horizon completion identified sets. `TemporalCpdag` mediation applies
  the existing DAG mediation identifier per completion and horizon, returning
  intervals rather than an enumeration-weighted point. Cheap/full run the
  mediation suite on each identified completion.
- Frequentist DBN Pulse / single-step Sustained cheap/full mix the existing
  temporal refuters by fixed graph weight. Multi-step windows use the full
  sequential refits described above.
- Scalar DAG graph-posterior `InterventionResponse` cheap/full run the
  plugin-level overlap / sampling-stability suite.
- Composite `analysis_result` artifacts retain response, posterior,
  mediation-grid, and structural-mixture axes together.
- Same-design and mapped prior transfer may ride licensed Bayesian Pulse,
  single-step Sustained, and temporal `ResponseCurve` on explicit
  `TemporalDag`. The pin is `conformance/bayesian/temporal_prior_transfer`:
  named source cell, target cell, and `PriorCatalog.filter_compatible`.
  Incompatible catalogs fail closed. Multi-horizon transfer requires identical
  adjustment-node semantics across horizons; conflict-sensitive composition is
  currently single-horizon because its shrinkage is data-dependent.
  Multi-step Sequence refuses transfer (no new filter).

## Broader correctness review

The [library review](../v1.6-library-review.md) also corrects existing numerical,
identification, estimation, state-space, resampling, counterfactual, and artifact
issues. Licensed matrix cells remain open. The changes include joint LGSSM
posterior paths and retained fitted parent effects, target-specific IPW
uncertainty, calendar-time HAC, constraint-valid graph sampling, whole-cluster
bootstrap, and stable probability calculations across measurement units.

## Explicit refusals

- Temporal DBN-posterior `ResponseCurve` / `InterventionResponse` stay closed:
  they require per-cell model-conditional draws and horizon-indexed mass.
- `TemporalCpdag` / `TemporalPag` posterior atoms are not mixed: posterior
  probabilities over incomplete graph classes need a nested class/atom mass
  contract rather than completion-enumeration weights.
- Nested Sequence and last-step collapse remain refused.
- Multi-horizon conflict-sensitive prior transfer remains refused until each
  horizon can resolve and retain its own conflict diagnostic.
- Temporal dose-by-horizon surfaces have a machine-readable absolute ceiling
  of one million cells. Checked arithmetic prevents axis-product overflow;
  the ceiling bounds the five unavoidable cell-scaled `f64` values to 40 MB
  before support/allocator overhead, and execution honors tighter
  `ExecutionContext` memory budgets for these buffers, including retained
  observation-bootstrap surfaces. This is a preflight lower bound, not a
  bound on total model-fitting or allocator memory.
- Function-valued `ResponseCurve` cheap/full, including the new TemporalCpdag/
  TemporalPag and DAG graph-posterior neighbors, remain typed n/a: cheap/full
  name the ATE-shaped scalar suite.
- Frequentist DBN-posterior Pulse/Sustained on `TemporalCpdag` / `TemporalPag`
  remain closed: completion enumeration is not posterior probability.
- Bayesian non-Complete temporal observations use the observed-data Gaussian
  SEM and latent-trajectory Gibbs sampler under the declared ignorable
  joint-trajectory CAR assumption and distinct priors. This parametric route
  does not reinterpret the Frequentist IPCW/KM/Cox estimators as a Bayesian
  likelihood. Its posterior bands are pointwise.
- Latent-confounded PAG natural mediation remains closed because the existing
  temporal mediation identifier assumes the linear identified DAG mechanism
  product; completion engineering cannot supply the missing cross-world
  identification theorem.
