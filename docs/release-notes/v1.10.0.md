# Antecedent 1.10.0

Unreleased cut of the `1.10.0` branch. 1.10 is a **composition** release of the
already-licensed support matrix: 341 licensed cells of 1423 meaningful
combinations. It does not add query kinds or identification theory.

## What 1.10 claims

- Every licensed cell has a first-class inspect/contract coordinate.
- Every licensed cell completes the Rust compiler path
  inspect → preview → execute → claim → consume
  (`every_licensed_cell_completes_the_compiler_path`). Independent consume
  must accept a verified program. TemporalPag uses the identified-PAG
  envelope fixture so execute cannot terminate as an unidentified refuse.
- Domain-separated identities, four reasoning slots, portable claims, and
  independent consume of contracted `analysis_result` artifacts.
- Ordinary one-call analyses retain reusable studies on prepared tabular /
  temporal scalar, class, posterior-mixture, and response routes.

## What 1.10 does not claim

- Parent-estimator oracle evidence is **not** inherited by the compiler
  path. The 341-cell lifecycle is composition-seam evidence
  (`internal_cross_check` on synthetic licensed-coordinate fixtures), not
  independent numerical truth or interval calibration.
- Python `.study` / `.export()` are not universal. Callbacks, custom
  estimator settings, RD, panel/event/multi-environment, and some discovery
  paths refuse them. The 341-cell claim is the Rust compiler path, not
  Python product retention on every cell.
- Execution-bound calibration is a **1.10 non-goal**. `CalibrationInfo` is
  `unavailable` unless a certificate is retained as `scope_not_assessed`.
  Interval coverage remains the 1.9 weekly gate
  (`scripts/gate_calibration.sh`).
- `result.answer` is the safe consumption interface. Historical `.effect` /
  `.ate` warn when a point display would misrepresent; they still return the
  scalar unless `ANTECEDENT_STRICT_ANSWER=1`. `.posterior` / `.response`
  remain accessible.
- `program_id` is the compiled program. `claim_id` is the execution claim.

## Release process

`gate_release.sh` is the PR inventory / composition umbrella. A green local
run is not an RC. Cut with `scripts/gate_release_candidate.sh`: calibration
surface identity against `CALIBRATION_SHA`, this inventory, Python
lint/pytest, and one local wheel. The CI `python-wheels` matrix remains
required on the candidate SHA. Everyday PRs do not run 400-replicate
calibration. `CALIBRATION_SHA` must resolve to a commit whose
`scripts/calibration_surface.list` tree matches HEAD.
