# Antecedent 0.7.1

0.7.0 added temporal response and evidence status. 0.7.1 is a **patch**:
Kennedy-DR curves no longer stay silent when a heavy-tailed outcome
dominates the least-squares nuisances. No public API rename. Licensed
cells are unchanged. Workspace and Python package versions are **0.7.1**.

## Correctness

`response.kennedy_dr` fits additive cubic GAMs by least squares. That
construction needs finite residual moments. A Cauchy (or spiked) outcome
could inflate the fitted curve by orders of magnitude while
`evidence_status` stayed `licensed` and `support.status` stayed
`supported` — overlap diagnostics look only at the treatment kernel.

Mean curves now always report `response.outcome_tail_ratio`
(`max |Y - median| / (1.4826 MAD)`, then the warning bound 20) and emit
`response.heavy_tailed_outcome` when the ratio exceeds the bound. A
1%/99% pseudo-outcome winsorization shift is
`response.pseudo_outcome_winsor_shift`; a large relative move emits
`response.pseudo_outcome_tail_sensitivity`. Point derivatives and the
Riesz ADE report the tail ratio.

Neither diagnostic demotes `evidence_status` or `support.status`. Those
axes remain the support-matrix cell and empirical treatment overlap.
`CausalResponseView` shows a warning count in its repr.
