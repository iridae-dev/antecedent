# Antecedent 1.4.0

Class-preserving graph coordinates, then handoff.

CPDAG ATE now compiles and estimates as `Cpdag`. Completions stay atoms of a
MEC envelope; a caller who orients the graph themselves still holds a `Dag`.
Static graph-posterior ATE now has a Frequentist combiner beside the 1.1
Bayesian envelope. See the [evidence ledger](../v1.4-evidence.md) for the
frozen mixture pins and the disclosed limits: multi-atom Frequentist
uncertainty is unavailable; temporal EconML handoffs refuse until offsets can
be preserved; conditional completions require a pre-treatment and augmented
adjustment check; Temporal PAG results disclose their restricted DAG-only
scope.
