Hand-written notes on the eight newly licensed temporal cells (counts above
are authoritative):

- `ResponseCurve` / `InterventionResponse` on `TemporalDag` require a
  temporal attachment (`horizons`, `policy`, `treatment_lag`). Static
  `ResponseCurve` without that attachment remains n/a on temporal graph
  classes.
- `InterventionResponse` licenses `Set`, `Soft(constant|additive_shift)`,
  and a single-step one-variable `Sequence`; multi-step and nested
  `Sequence` policies fail closed.
- `PulseEffect` / single-step `SustainedEffect` dispatch through
  `TemporalLinearAdjustment` directly. Point estimates agree numerically with
  the dose × horizon surface on the shared fixture, but **standard errors can
  diverge**: the surface path uses analytic delta-method bands while Pulse /
  Sustained carry the `Study` bootstrap configuration.

## Sharp edges for adopters

- **Horizon-specific identification.** A multi-horizon surface identifies
  once per requested horizon at prepare time (`I(h)`), not once at
  `max(horizons)`. Confounding that reaches a short outcome but not a longer
  one must not reuse the long-horizon empty set. Inspect
  `identification.horizon_adjustment_sets`. A union of those sets is not a
  valid shared adjustment set.
- **Horizon-specific empirical support.** `support.status` on a dose ×
  horizon surface is a three-way summary (fully supported / partially
  extrapolative / outside). Inspect `support.point_status` for the cell
  grid. A dose inside the union of horizon ranges can still be outside a
  long-horizon lag window.
- **Refuters on temporal response.** Scalar ATE refuters do not apply to a
  function-valued dose × horizon surface. Python results expose a skipped
  validation check `refute.temporal_response.skipped` on
  `CausalResponseView.validation`; Rust `Study` diagnostics carry the same
  code. `PreparedAnalysis.refute` stays AverageEffect-only.
- **Pulse vs surface uncertainty.** Compare point estimates across
  `PulseEffect`, `SustainedEffect`, and `ResponseCurve`; do not expect
  bootstrap SEs from the contrast path to match analytic surface bands.
- **Prepared path.** Temporal response uses `PreparedAnalysis.prepare` (or
  `Study::prepare` in Rust) to cache identification once; `identify()` remains
  `AverageEffect`-only on static graphs.
- **Examples.** See `examples/python/temporal_response_curve.py` and the Rust
  peer `temporal_response_curve`.
- **Query policy.** Python reads `TemporalResponseSpec::license()` (horizon
  cap, allowed policies, default treatment lag) instead of mirroring those
  values.
- **Evidence status travels with the result.** Licensed and allowlisted
  cells both build successfully. The distinction is on the prepared
  analysis and the returned artifact (`StudyResult.support_status` /
  Python `evidence_status`), not only at dispatch. Treat
  `allowed_unlicensed` as "this path runs" — not as a licensed claim.
  The Cartesian support-matrix product is an axis product, not a feature
  score; most cells are typed n/a, not missing work.
- **Pointwise homoskedastic OLS bands.** Temporal-response 95% bands are
  pointwise delta-method SEs from the full homoskedastic OLS coefficient
  covariance. They are not simultaneous bands. Serially correlated or
  heteroskedastic innovations can make nominal coverage optimistic. The
  assumption is declared on the estimate (`ols.homoskedastic.pointwise`).
  Empirical `SupportReport` is a dose-range statement, not positivity /
  overlap conditional on the adjustment set.

Evidence: `conformance/response/temporal_dose_horizon` (surface, bands,
Pulse / Sustained projection, Set / Soft / single-step Sequence);
`conformance/response/temporal_confounded_pulse` (adjustment set
`Z@-1`, identified estimand `temporal.backdoor.unfolded`, and the
structural estimate under confounding); `conformance/response/temporal_horizon_support` (per-horizon
empirical support).

Temporal response pointwise bands compute the delta-method standard error of
the g-computed level from the full homoskedastic OLS coefficient covariance
(propagating intercept and adjustment-covariate uncertainty), replacing the
previous treatment-coefficient-only approximation that produced a zero-width
band at dose zero.
