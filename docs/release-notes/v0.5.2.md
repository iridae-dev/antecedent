# Antecedent 0.5.2

0.5.1 made the claim→evidence chain machine-checkable. 0.5.2 is a performance
pass with a localized correctness audit. No public API rename. Workspace and
Python package versions are **0.5.2**.

## Faster prepared clicks and hot paths

`Study::prepare` now runs static identification once; each `PreparedStudy`
estimate click reuses it (observable as `exec.identify.cached`). The Python
`PreparedAnalysis` handle holds that study behind an `Arc`.

IO section lookup is indexed; Laplace Newton and HMC leapfrog reuse workspace
buffers; exact Shapley (`k ≤ 16`) uses a dense coalition cache; Arrow analyze
records `bytes_borrowed`. Panel refutation reuses unmutated unit-column Arcs.
Static OLS sensitivity is one Gram plus per-point Cholesky (temporal / ridge /
lasso / Huber keep the data-pass).

## Localized correctness

Nested counterfactuals refuse row-coupled mechanisms that mixed other units'
noise. Temporal CPDAG/PAG reject future→past arrowheads. Linear/GLM adjustment
honor `TargetPopulation::Predicate`. GLM ATT/ATC analytic SEs use the arm-law
gradient. Trimmed IPW Hajek SEs use retained n. Newey–West after trim/matching
requires panel times. PAG GAC forbids `Forb(T,Y)`, not all of `De(T)`. Sensitivity
Gram compiles on the post-replace complete-case set.

Full details in the [CHANGELOG](https://github.com/iridae-dev/antecedent/blob/main/CHANGELOG.md).
