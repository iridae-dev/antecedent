# Antecedent 0.6.1

0.6.0 was the contract cut. 0.6.1 is a **patch**: correctness on Bayesian
envelopes and Python ingest, a discovery RNG pin, and the hot-path work that
followed the cut. No public API rename. The support matrix is unchanged.
Workspace and Python package versions are **0.6.1**.

## Correctness

Interactive Bayesian envelopes now prepare (and, for temporal DBN posteriors,
fit) **before** stratified Interactive subsample, and they keep the prior
anchor in the original atom order so subsample cannot drop the anchoring
graph. PC parent selection under `BlockShuffle` keeps its RNG salt at 0, so
parent sets stay bit-identical to 0.6.0.

Python `PreparedAnalysis.prepare` uses the same Arrow CDI ingest path as
`analyze`. `np.asarray` on a posterior artifact follows a locked copy
contract; ingest errors match across NumPy and Arrow.

## Performance

Prepared clicks no longer clone the `Study`. Kennedy curves reuse GAM
workspace, row scratch, and local-quadratic weights across the mean-curve
grid. Gaussian g-comp uses a closed-form contrast; AIPW borrows design
columns when nothing is trimmed; conjugate Gram stats cache across
prior-scale refits; PC parent CI tests batch per conditioning level.
Python prefers Arrow CDI on prepared clicks and typed-graph ATE, and
exposes posterior draws to NumPy without cloning the `Vec`.
