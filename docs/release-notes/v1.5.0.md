# Antecedent 1.5.0

Local, distributional, joint. ConditionalEffect grids publish per-arm
`F_a(c)` bands and tail support, prepared batches freeze a shared fold /
covariate design, and PAG `InterventionResponse` mixes multi-atom IFs only
when every completion is identified. See the
[review and evidence ledger](../v1.5-evidence.md).

Implemented paths include binary/joint score retargeting, AIPW and
class-aware ConditionalEffect exceedance grids, requested-cell joint AIPW
(including cheap/full validation; point CDE via `continuous_cell` is a named refuse),
shared-row IF covariance for static effects and responses, `PreparedBatch`
with estimate-artifact candidate-selection provenance, and estimate-attached
E-values on CoDetermined tier closure. Bidirected CoDetermined defaults to
generalized adjustment + AIPW, not `general.id`. `analyze()` and
`PreparedAnalysis.prepare` accept `TieredBackground` and keep outcome
functionals. Temporal/DBN multi-atom Frequentist uncertainty stays 1.9.
