# Antecedent 1.7.0

Released 2026-09-13. Class-preserving Bayesian (and remaining Frequentist
policy/observation) analyses on incomplete temporal graphs. The
[support matrix](../support-matrix.md) is the license.

## What changed

- `TemporalCpdag` / `TemporalPag` Pulse and Sustained run Bayesian
  per-completion temporal g-computation without collapsing the class to a
  `TemporalDag`. Without a caller-supplied `ClassPrior` the result is an
  identified set plus atom posteriors. Enumeration weights are not mixed.
  With `ClassPrior`, `aggregate_effect_envelope` mixes at draw level and
  retains unidentified mass.
- Multi-step Sustained on incomplete classes uses sequential g-computation
  on directed completions. Bidirected MAG completions stay unevaluable.
  The window is not collapsed to the last step.
- Bayesian class `ResponseCurve` / `InterventionResponse` publish
  per-horizon identified sets. A class-prior curve publishes
  `conditional_on_identified` only when every identified atom is aligned
  and unidentified mass is zero.
- Sequence / Soft overlays identify per directed completion. A joint
  coordinate miss unidentifies that completion, not the class. Nested
  Sequence stays refused.
- Licensed 1.3/1.6 observation pairs ride incomplete-class curves and
  Sequence per completion. Complete-data bands are not reused. Delayed
  entry, interval, and truncation stay refused.
- `TemporalCpdag` Bayesian mediation composes per completion and horizon.
  The primary scalar stays an identified set. TemporalPag natural
  mediation stays closed.
- `identify()` accepts temporal `Response` and TemporalCpdag mediation and
  returns `Identification::TemporalEnvelope` with stable completion
  fingerprints for `ClassPrior`.
- Prepared clicks cache class identification and emit `exec.identify.cached`.
- Mechanism prior transfer binds per completion. A conflict diagnostic
  does not flip identification. Multi-step Sequence transfer stays refused.
- Incomplete-class × `graph_posterior` stays closed. Completions are not
  DBN-posterior atoms.
- `StudyBuilder::max_completions` / Python `max_completions=` cap the
  completion search explicitly; a cap cannot claim class-wide identification.
- Shared numerical kernels (ranks, QR rank, splines, likelihood tails,
  predictive mixture checks, GAM GCV) are scale-invariant; see
  [the shared mathematics review](../mathematical-review-2026-09-13.md).

## Explicit refusals

- TemporalPag natural mediation remains closed because the existing
  temporal mediation identifier assumes the linear identified DAG mechanism
  product; completion engineering cannot supply the missing cross-world
  identification theorem.
- `TemporalCpdag` / `TemporalPag` × `graph_posterior` stays closed:
  `execute_dbn_posterior_bayesian` is TemporalDag-shaped. Completion
  enumeration is not posterior probability.
- DBN-posterior response on incomplete classes stays closed.
- Static Bayesian derivatives, static Bayesian mediation, and Bayesian
  counterfactuals remain 1.8 work.
- Function-valued cheap/full stay typed n/a.
- Delayed entry, interval, and truncation observation stay refused on
  incomplete classes.
