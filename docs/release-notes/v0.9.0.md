# Antecedent 0.9.0

0.9.0 closes the support matrix and brings prepared analyses to parity with
the licensed one-shot paths. Unsupported combinations no longer run under an
`allowed_unlicensed` escape hatch: they are classified as typed
not-applicabilities or refused before execution.

## Prepared analyses

`PreparedAnalysis` now covers PAG and ADMG ATE, graph-posterior ATE,
temporal pulse and sustained effects, DBN-posterior temporal effects, and
temporal mediation. Re-estimation preserves series semantics, and second-click
Bayesian refutation on a single-graph Dag includes prior and posterior
predictive checks. The multi-graph PAG envelope is the exception: it runs the
effect refuters on the mixture mean and records a `refute.bayesian.ppc.skipped`
diagnostic instead of a PPC suite.

Parity here is over which cells accept `prepare()`, not over caching. PAG
envelopes, bidirected ADMGs, and graph posteriors accept a prepared study but
cache no identification: they re-identify on every click, and each licensed row
says so in its `limitations`. Caching them is 1.x optimization work, not a
missing cell.

Prepared analyses reject identifier, estimator, prior-transfer, and mapping
options when the selected path cannot apply them rather than silently
discarding those options.

## Boundary correctness

Python distribution, path-specific, discovery, and temporal effect entry
points propagate requested refutation suites into the native analysis.
Function-valued response queries reject scalar suites as not applicable.
PAG, CPDAG, and ADMG analyses also validate graph variable names and order
against Arrow columns before estimation.

## Frozen public contracts

The Python root is frozen at 49 exports through 0.9. Fourteen additional
modules remain reachable but deliberately outside `antecedent.__all__`.
`TemporalCpdag` and `TemporalPag` stay on `antecedent.graph`; derivative query
types stay at the root so unsupported analyses return typed refusals rather
than disappearing from the API.

Durable artifact format 0.4 is the wire-format freeze for 1.0. Existing
migration and cross-language round-trip tests cover the implemented query and
result variants.

The 0.9 release invariant is zero active allowlist entries. The
`allowed_unlicensed` wire value remains decodable for compatibility, but new
allowlist rules fail the support gate.

## Graph-posterior scope

Licensed graph-posterior analysis is intentionally narrow:

- Bayesian `AverageEffect` envelopes over DAG atoms support validation
  `none`, `cheap`, and `full`.
- Bayesian pulse and single-step sustained envelopes over `TemporalDag` atoms
  support validation `none`; cheap/full are refused because the DBN path
  returns no refutations.
- Frequentist graph-posterior cells, response mixtures, and
  ADMG/CPDAG/PAG posterior atoms are refused.

Identification runs per atom on each prepared estimate click. Unidentified
atom mass is retained, and priors do not upgrade identification. The current
evidence contract is prepared-vs-fresh internal cross-checking, not a
known-truth pin for the mixture effect. Bayesian PAG ATE is a separate
completion/generalized-adjustment envelope, not a `graph_posterior` structure
cell.

Path-specific and interventional-distribution cheap/full validation, and
temporal-mediation cheap/full validation, remain refused: those execution
paths return no query-native refutation suite.
