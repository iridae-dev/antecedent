# Antecedent 0.9.0

!!! warning "Draft — 0.9.0 is not released"
    The 0.9 audit in `TODO.md` is still open. This page describes work that has
    landed and been verified on the cut branch; it is not a shipped release and
    the licensed matrix below is not yet frozen.

0.9.0 closes the support matrix and brings prepared analyses to parity with
the licensed one-shot paths. Unsupported combinations no longer run under an
`allowed_unlicensed` escape hatch: they are classified as typed
not-applicabilities or refused before execution.

## Prepared analyses

`PreparedAnalysis` now covers PAG and ADMG ATE, graph-posterior ATE,
temporal pulse and sustained effects, DBN-posterior temporal effects, and
temporal mediation. Re-estimation preserves series semantics, and second-click
Bayesian refutation on a single-graph Dag includes prior and posterior
predictive checks. The multi-graph PAG envelope is the exception: it runs the
effect refuters on the mixture mean and records a `refute.bayesian.ppc.skipped`
diagnostic instead of a PPC suite.

Parity here is over which cells accept `prepare()`, not over caching. PAG
envelopes, bidirected ADMGs, and graph posteriors accept a prepared study but
cache no identification: they re-identify on every click, and each licensed row
says so in its `limitations`. Caching them is 1.x optimization work, not a
missing cell.

Prepared analyses reject identifier, estimator, prior-transfer, and mapping
options when the selected path cannot apply them rather than silently
discarding those options.

## Boundary correctness

Python distribution, path-specific, discovery, and temporal effect entry
points propagate requested refutation suites into the native analysis.
Function-valued response queries reject scalar suites as not applicable.
PAG, CPDAG, and ADMG analyses also validate graph variable names and order
against Arrow columns before estimation.
