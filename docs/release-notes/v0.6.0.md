# Antecedent 0.6.0

0.5.2 was a performance pass. 0.6.0 is the **contract cut**: every public
sentence about what Antecedent will run is a machine-checked cell. This is
not a filled matrix. Workspace and Python package versions stay **0.5.2**
until the cut is accepted.

## The matrix is the license

The public license is the generated
[support matrix](../support-matrix.md)
([ADR 0020](../../adr/0020-support-matrix-and-prepared-workflow.md)).
`docs/capabilities.md` is inventory; it does not license a cell.

A cell is exactly one of **licensed**, **n/a**, or **refused**. Default is
refused. `pending` is illegal on a cell. `analyze` / `Study::run` is sugar
over identify → prepare → estimate; a combination that only works inside
`analyze` cannot be licensed.

As of this draft the generated matrix reports 2394 cartesian cells: 16
licensed, 1218 n/a, 816 enforced refusals, 344 default-refused (still run
until licensed or closed). Those counts are generated; they are not a
freeze.

## Licensed cells

Sixteen staged cells, all Frequentist on a Dag:

- `AverageEffect` × `explicit` / `accepted` × validation `none` / `cheap` / `full`
- `ResponseCurve` × `explicit` / `accepted` × validation `none`
- `ConditionalEffect` × `explicit` / `accepted` × validation `none` (prepared
  handle, `ConditionalLinearAdjustment` estimator)
- `PathSpecificEffect` × `explicit` × validation `none` (prepared handle,
  `PathSpecificNatural` identifier + `FunctionalEffect` estimator)
- `InterventionalDistribution` × `explicit` × validation `none` (prepared
  handle, `GeneralId` identifier + `FunctionalDistribution` estimator; the
  known-truth fixture pins identification, not the estimation layer)
- `InterventionResponse` × `explicit` / `accepted` × validation `none`
  (prepared handle, `response.intervention_gcomp` estimator; the known-truth
  fixture pins a hard `Set` intervention under a deterministic linear
  structural mean)

## Enforced refusals and n/a

`parity/support_closed.toml` fail-closes Counterfactual, MediationEffect,
and SustainedEffect (not on the staged handle); derivative queries (only
`ResponseCurve` on a Dag is staged); `ResponseCurve` on Pag / Cpdag / Admg;
and PathSpecificEffect / InterventionalDistribution on `accepted` or
`graph_posterior` (only their `explicit` Dag cell is staged). TransportQuery
and InterferenceQuery are closed as analyze cells.

Graph-posterior × response is Option B: **n/a** (contrast-only). ATE ×
graph posterior stays as today (per-graph identify inside `execute()`, no
`identify_only`).

Stage transport and interference are not licensed `analyze` cells. The
implemented sID subset plus `NotCertified` is the transport contract.
