# Antecedent 2.1.1

2.1.1 corrects two contract disclosures in 2.1.0. Estimation is unchanged.

Bayesian average effects on an ADMG were computed and then rejected at export. `inference()` binds `bayesian.gcomp` on every static average effect when the caller does not choose an estimator. On an ADMG the checked plan resolves `functional.effect`. The contract advertised both names, and verification requires a functional program only when every advertised estimator is `functional.effect`. 2.1.1 advertises the resolved estimator when that `bayesian.gcomp` binding is a placeholder. A caller-selected estimator is still advertised, including when it disagrees with the plan.

Graphless point results recorded `off_axis` on the support slot of the exported artifact and omitted it from the live contract, so inspect reported support as missing. 2.1.1 copies the slot status into the live contract. Bernoulli randomized effects and panel difference-in-differences are two routes this affected.

A plain panel difference-in-differences also dropped its graphless support label on load. The live answer published `unlicensed_point_utility`, or `off_axis_interval_evidence` when an interval was present, and the loaded answer omitted it. 2.1.1 fills that label from the same rule when the artifact leaves the license unset.

## Explicit refusals

2.1.1 licenses no new coordinate and withdraws none. Unlisted geometric coordinates still refuse; see the [support matrix](../support-matrix.md#refusal-reasons) and the [graphless support matrix](../graphless-support-matrix.md).
