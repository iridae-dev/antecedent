# Antecedent 1.9.0

Unreleased. Calibration of licensed intervals: every licensed cell was
reviewed for mathematical errors and for claims that exceed the code or the
evidence ([cell review](../v1.9-cell-review.md)), and the intervals those
cells publish are now checked by repeated-sampling coverage. Intervals that
missed were fixed; where no fix was available the measured coverage is
published as a boundary record and disclosed at runtime. The
[support matrix](../support-matrix.md) is the license. Short-series
measurements: [short-series thresholds](../short-series-thresholds.md).

## What changed

- **Calibration gate.** `scripts/gate_calibration.sh` runs 400 replicates
  per target (200 for the bootstrap Hájek IPW target) against a two-sided
  `level ± 3·MCSE` band (±4.5 points at 90%), so over-coverage fails as well
  as under-coverage. Multi-atom targets use fixtures whose identified atoms
  disagree; temporal targets add AR(1) residuals and series down to n = 60.
  It runs weekly and on manual dispatch (`.github/workflows/calibration.yml`),
  not in `gate_release.sh`.
- **Gated versus boundary.** A gated cell asserts the band. A boundary record
  is measured and printed but not asserted, and the result carries a warning
  naming the scope: temporal response bands under AR(1) ρ = 0.9 residuals
  (0.883–0.943 pointwise, 0.873 simultaneous at nominal 0.95) and a shift
  response under a persistent AR(1) φ = 0.9 treatment
  (`response.temporal.block.persistence_boundary`); short or persistent
  series on the scalar temporal effects
  (`estimate.temporal.circular_block_se.short_series`, thresholds per SE
  family: 45 for Pulse / single-step Sustained, 40 for mediation and for
  multi-step Sustained, 155 for mixtures); and misspecification probes (`bayesian.gcomp` with an omitted
  term, the Gaussian-score ADE under a skewed treatment).
- **Serially dependent rows.** Frequentist temporal SEs resample circular
  blocks of lag-aligned rows with a dependence-aware block length (lengthened
  when any estimating score, residuals included, is persistently dependent)
  and a circular-Bartlett fixed-b factor and a Bartlett kernel-bias factor of
  the estimating scores; iid analytic SEs are NaN. Temporal
  response bands use their own dependence-aware rule and refit every horizon
  on the same calendar times. Bayesian temporal likelihoods, including both
  temporal mediation mechanisms, are tempered by a REML-fitted autoregressive
  variance ratio with a residual-scale term and the factor's own delta-method
  spread (a generalized posterior), calibrated for short-memory dependence —
  AR(2), ARMA(1,1) and MA(2) at n = 60–400 — not long memory.
- **Fixes.** The shared circular-block mixture SE was inflated
  1.35–2.3×; temporal mediation omitted mediator–outcome confounders;
  path-specific effects returned the total effect when another path existed
  and the recanting-witness check over-refused; the linear-adjustment
  influence function understated envelope SEs; AIPW ATT/ATC, Kennedy-DR band
  and g-computation level SEs missed coverage; second point derivatives used
  a local cubic where a local quartic is needed (order-2 coverage
  0.695 → 0.880); identified-set intervals now use per-completion endpoints.
- **Missing data.** Null Float64 cells (Arrow nulls, NumPy/pandas NaN) were
  stored as 0.0 and could be read as observed zeros; a NaN built from raw f64
  slices stayed valid. Both are now missing cells, dropped from complete-case
  estimates like a missing row; temporal paths fail closed with
  `IncompleteSeries`.
- **New licensed cells (330 → 341).** Accepted-Dag `Counterfactual`
  (Frequentist and Bayesian, `none`); ADMG `InterventionalDistribution`
  (explicit and accepted, Frequentist and Bayesian, `none`), whose Frequentist
  atoms carry a logit-bounded probability interval (bounded to `[0, 1]`, not a
  partial-identification bound), Rust Study API only; single-horizon
  Frequentist DBN-posterior `TemporalMediationEffect` (`none`) with a shared
  circular-block SE for the frozen-weight aggregate; explicit-Dag
  `AnomalyAttribution` / `ChangeAttribution` (Frequentist, `none`); Admg
  `TransportQuery` trial-to-target IPW (Frequentist, `none`); and Dag
  `InterferenceQuery` NeighborCount HT/Hájek (Frequentist, `none`, Young
  variance). Attribution, transport, and interference are Rust Study API only.
  Python root `__all__` is 52 names (`AnomalyAttribution` /
  `ChangeAttribution` for the query axis; `analyze()` refuses both).
  Prepared panel Pulse/Sustained now prepare and refresh; panel responses stay
  refused.

## Behaviour changes

- Temporal response bands carry a per-cell kernel-bias factor and a
  short-series warning; the shift response under a persistent treatment is now
  gated, and AR(1) ρ=0.9 residuals remain a disclosed boundary whose long-run
  ratio is not estimable at n ≤ 1000.
- Production runs evaluate every requested bootstrap replicate and posterior
  draw. The previous adaptive budget stopped static bootstraps at 10–24
  replicates whatever was requested, so published SEs carried 15–22% Monte
  Carlo error and the 50→199 default had no effect on static cells. Bootstrap
  SEs are more precise and bootstrapped runs take roughly the replicate ratio
  longer (8–17× at the default 199, single-threaded).
- `rd.sharp` reports the HC1 residual-sandwich SE by default; the
  homoskedastic SE is an opt-in (`RdConfig::with_se_kind`; Python
  `estimator_config={"se_kind": ...}`). Point estimates are unchanged;
  `se_analytic` changes for every `rd.sharp` result.
- At the Interactive latency tier, graph atoms left out of the 16-atom
  subsample are reported as `subsampled_out_mass`, not as unidentified mass,
  and Bayesian graph-posterior and DBN-posterior ATE results are
  `GraphDependent` whenever unidentified or subsampled-out mass is present.
- A graph posterior that lists the same DAG more than once weights it once by
  its combined mass (it entered with k² times its per-sample weight).
- `AnalyticSeKind::Hc2` / `Hc3` on influence-function SE paths (AIPW, Wald
  IV and others) return an error instead of the HC1 value; `Hc0` there now
  computes the uncorrected sandwich.
- NaN and null Float64 cells are missing, as above.
- The temporal mediation short-series warning fires below 40 score effective
  rows (was 35).
- The default bootstrap replicate count is 199 (was 50): the Rust `Study`
  default, the Python `standard` latency tier and untiered `analyze()`.
- Observation-adjusted Sequences whose unfolded design reads the outcome at a
  nonzero lag are refused.
- Frequentist multi-atom graph-posterior curves withhold their band; the
  joint-IF SE is published only for a scalar aggregate.

## Explicit refusals

- Frequentist DBN-posterior `TemporalMediationEffect` cheap/full, and
  multi-horizon grids, stay refused.
- Temporal graph-posterior response mixtures and TemporalCpdag/TemporalPag
  posterior atoms stay refused.
- ADMG `InterventionalDistribution` cheap/full and conditional (IDC) tables
  stay refused.
- Graph-posterior path, distribution, derivative and counterfactual mixtures
  stay refused; `Counterfactual` cheap/full and nested counterfactuals stay
  closed.
- Panel `ResponseCurve` / `InterventionResponse` stay refused.
- `AnomalyAttribution` / `ChangeAttribution` cheap/full, Bayesian, accepted,
  and graph-posterior stay refused; `MechanismChange` and `UnitChange` stay
  off the public query axis.
- `TransportQuery` outside explicit Admg Frequentist `none` stays refused,
  including RecursiveFactorization and NotCertified.
- `InterferenceQuery` outside explicit Dag Frequentist `none` stays refused;
  variance is the Young bound, not Aronow–Samii.

Every licensed row names the test that executes it; the exemption list for
rows licensed before that rule (`parity/_evidence_test_backlog.txt`) is empty.
