# 1.10 practitioner walkthrough

This walkthrough is written against the same typed records execution uses:
`Study::inspect`, `PreparedStudy::contract`, `preview_transform`,
`encode_contracted_result`, and `consume_analysis_result`. It is not a
notebook-only demonstration.

Acceptance path (DAG `AverageEffect`):

1. **Discover / review** an `AcceptedGraph`, or supply an explicit DAG.
2. **Prepare** a `PreparedStudy`. Identification products stay on that handle.
3. **Inspect** (`Study::inspect`) for cheap structural classification. Identification
   and uncertainty slots and the program identity are explicitly unavailable.
4. **Contract** (`PreparedStudy::contract`) projects cached identification,
   support-matrix coordinates, and domain-separated identities.
5. **Preview** a transformation. A preview binds input identities and cannot
   authorize execution after those identities change, and it reports the
   refusal the apply raises when the handle cannot perform it.
6. **Execute or refuse.** `estimate` / `apply_refresh` / `apply_retarget` consult
   the same support and retarget owners as 1.5.
7. **Export** `encode_contracted_result` onto the existing `analysis_result`
   container. The contract section stores rehashable graph/expr payloads.
8. **Independent reload.** `consume_analysis_result` / Python `artifacts.accept`
   verify from bytes alone. Old artifacts remain readable and are not promoted.
9. **Checked derivation / presentation.** Four reasoning slots — Identification,
   Support, Uncertainty, Assumptions — render from structured state.
10. **Onward handoff.** A receiving system may store or forward an envelope
    without accepting it as a verified program.

Panel promotions shipped in 1.10 and run on the same path as licensed cells:
Frequentist and Bayesian panel `ResponseCurve` / `InterventionResponse` on a
supplied `TemporalDag` average per-unit surfaces with between-unit bands, and
panel class Pulse / Sustained on `TemporalCpdag` / `TemporalPag` fit each
identified completion on panel units and mix by completion mass (the
`compiler.panel_*` rows in `parity/compiler.toml`). Composition metadata
cannot grant a license.

This walkthrough is one DAG `AverageEffect` acceptance path. Every licensed
cell inspects as a first-class contract and completes the same Rust
compiler path. This verifies composition across stages; it does not establish
estimator accuracy. Python support is separately scoped: successful licensed
Python analyses retain `result.study`; Rust-only cells remain Rust-only.
