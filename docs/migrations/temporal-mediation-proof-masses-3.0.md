# Temporal mediation inspection proof masses

`CheckedTemporalClassMediationInfo.proof_masses` now reports a record for each requested horizon, in request order. Fixed-class values use raw completion enumeration weights; graph-posterior values normalize the stored nonnegative graph weights to posterior probabilities, summing identified and unidentified weights separately. `truncated_completions` is the recorded truncation counter or marker, when applicable: a nonzero value signals incomplete retained proof and does not measure unenumerated mass. For class posteriors it sums recorded counters across unique retained class atoms.

The Rust `atom_count`, `identified_mass` and `unidentified_mass` fields are now `Option` aliases: they are `Some` for a single requested horizon and `None` for multiple horizons. Python's corresponding operation-inspection fields are numbers for one horizon and `None` for multiple; use `proof_masses` for the horizon-specific values and basis. DBN posterior inspection now uses each horizon's actual eligible graph projection rather than the union across horizons. These fields describe retained identification proofs, not numerical estimation success or calibration. No study result, target or claim identity changes.
