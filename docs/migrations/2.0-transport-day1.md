# 2.0 transport day-1 UX

One ordinary question, the existing verbs, one result shape. The native
compiler is unchanged.

## Moved in 2.0

`antecedent.transport` now exports only the day-1 names. The 1.11 names below
are gone from `antecedent.transport` and from the package root, and raise an
`AttributeError` that names the new home:

| 1.11 spelling | 2.0 spelling |
|---|---|
| `antecedent.TransportQuery` | `antecedent.transport.advanced.TransportQuery` (trial-IPW cell) or `antecedent.transport.Transport` (ordinary question) |
| `antecedent.transport.TransportQuery` | `antecedent.transport.advanced.TransportQuery` |
| `antecedent.transport.identify` | `antecedent.transport.advanced.identify` (the root `antecedent.identify` verb is unchanged) |
| `antecedent.transport.estimate_trial_effect` | `antecedent.transport.advanced.estimate_trial_effect` |
| `SelectionDiagram`, `TransportIdentification`, `TransportCertificate`, `NonTransportableCertificate`, `DirectFormula`, `StandardizationFormula`, `RecursiveFactorizationFormula`, `PopulationFactor`, `TrialTransportEstimate` | same names under `antecedent.transport.advanced` |
| `OverlapDiagnostic`, `TransportOverlapReport` | no longer exported; they are the types of `TrialTransportEstimate.overlap` |

## Day-1 loop

```python
import antecedent as ant

query = ant.transport.Transport(
    ant.ResponseCurve("price", "sales", grid=[8, 9, 10, 11, 12]),
    target="new_market",
    evidence=evidence,
)
result = ant.analyze(data, graph=graph, query=query)
# result.answer / .response / .calibration / .inspect() / .study / .export()
```

More control stays on the same verbs:

```python
ident = ant.identify(graph=graph, query=query)
result = ident.estimate(data, provider=ant.transport.LearnedCategorical())
```

The licensed trial-IPW cell is `antecedent.transport.advanced.TransportQuery`
(explicit `trial=` / probability columns). The 2.0 spelling is
`antecedent.transport.Transport`.

## Evidence

```python
evidence = ant.transport.Evidence(
    source=ant.transport.Source(
        "trial", kind="experimental", interventions=["price"], sampling="independent",
    ),
    target_sampling="representative_sample",
)
query = ant.transport.Transport(
    ant.ResponseCurve("price", "sales", grid=[8, 9, 10, 11, 12]),
    target="new_market",
    evidence=evidence,
    selections=["preference"],
)
```

`Source.sampling` is the source draw design. `Evidence.target_sampling` is
the target-population law claim. Shared selection differences live on
`Transport.selections`; complementary sources override with `Source.selections`.

Inferred from `data` at `analyze` / `prepare` time: column names, measured
variables, snapshot digest, schema. Never inferred: population identity,
selection differences, observational vs experimental regime, intervention set,
sampling/dependence, target-sampling claim.

`data` is a mapping of population tables, a single table when there is one
bound snapshot, or the existing exact / statistical / trial snapshot types.

## Providers

Default `provider=EmpiricalTable()` (exact laws when `data` is
`ExactTransportData`). The conservative provider does not auto-promote.

- `LearnedCategorical` adds model assumptions and does not establish positivity.
- `TrialAipw` requires known randomization and an explicit provider on
  `AverageEffect` + `TrialAipwData`.

`provider=`, `inference=TransportInference(...)`, and `controls=` are refused
on non-transport queries.

## Results

- `AverageEffect` lowers to the binary `[0, 1]` contrast → `AnalysisResult`
  with `answer.kind="point"` (or `"unavailable"`).
- `ResponseCurve` → `CausalResponseView` with `answer.kind="response"`.
  Local support failures stay in `result.support`.
- Shared methods: `answer`, `inspect`, `refresh`, `export`, `load`, `study`,
  `calibration`.
- Lineage is `result.transport` (formula, provider, bindings, replicate IDs).
  Specialist views remain on `result.transport.distribution`.
- Day-1 `export()` / `load()` rehydrates the wrapped view. It is not a
  verified analysis program. Specialist objects from `transport.advanced`
  keep their own prefixes.

If the formula is identified but a factor is unbound,
`Identification.inspect()` support slot and `result.answer.detail` name the
joint. Malformed requests still raise.

## Advanced surface

Theorem-stage request types live only in `antecedent.transport.advanced`:
`ExactTransportQuery`, `StatisticalTransportQuery`,
`TransportResponseGridQuery`, `TrialAipwQuery`, `TransportQuery`,
`identify_classical`, `identify_meta`, `transport.advanced.prepare(...)`.
