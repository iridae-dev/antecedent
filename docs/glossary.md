# Read the scientific standing of an answer

These terms describe different checks. Read them together in `result.inspect()` rather than treating any one label as a general guarantee.

| Term | Meaning | Example |
| --- | --- | --- |
| Identified | Declared causal assumptions determine the requested quantity through an implemented identification route. | A backdoor adjustment identifies an average effect under the supplied DAG. |
| Supported / licensed | The exact configured route can execute with its recorded scope, evidence obligations and limits. “Licensed” is an implementation contract, not a legal license. | An estimator supports the all-observed mean ATE but refuses another functional. |
| Calibrated | A matching coverage record attests the executing code and assesses this execution's scope. | An interval outside the record's sample-size or configuration scope is not calibrated by that record. |
| Point-only | A numerical estimate without an interval claim. | A finite-law decision value can be exact under the supplied law and still lack a sampling interval. |
| Structural envelope | A range across declared structural possibilities. | Effects across CPDAG completions; not a confidence interval. |
| Assumption range | A range across a declared sensitivity set. | Varying an invariance premise changes the transported answer. |
| Attested | A caller or provider declares a claim or its provenance. | An external callback's reported mean remains externally attested. |
| Verified | A particular object has passed its specified checker. Check what the receipt verifies. | Artifact identity verification does not verify a real-world causal assumption. |
| Identity-bound | Consumption matches an independently retained expected identity. | The consumer uses an expectation saved separately by the producer. |
| Replayable | The consumer can recheck or recompute the supported recorded computation. | A finite composition can be re-derived from its artifact. |
| Resumable | An explicit route permits future execution from retained state and required inputs. | Loading a result does not itself restore a live study. |
| Empirical support | Supplied observations or laws support the requested coordinates. | A response grid keeps an unsupported dose visible rather than silently deleting it. |
| Numerical uncertainty | Error due to finite computation or simulation. | A Monte Carlo band is not a sampling confidence interval. |

For handling outcomes, read [refusal and partial knowledge](refusal-and-partial-knowledge.md). For exact supported combinations, use [supported analyses](supported-analyses.md). For scope-specific coverage, use [population, time and uncertainty](population-time-uncertainty.md).
