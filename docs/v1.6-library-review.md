# Broader 1.6 library review

This second review covers existing library behavior as well as the new temporal
release work. It was divided across numerical inference, graph/identification,
estimation/validation, and model/state/application boundaries. All licensed
support-matrix cells are preserved; corrections implement the claimed behavior
rather than narrowing the matrix.

## Mathematical corrections and evidence

| Area | Corrected behavior | Regression evidence |
| --- | --- | --- |
| Probability functions | Negative erf has the correct sign; erfc retains representable subnormal tails; normal quantiles respect endpoints and tiny probabilities. | Kernel and statistical special-function tests, including odd symmetry and tail pins. |
| Posterior diagnostics | R-hat, ESS, and movement checks do not change with measurement units; the final even-length IPS pair is retained; invalid layouts do not panic. | MCMC scale/layout regressions and the hand-calculated ESS = 8/7 case. |
| Distribution tests | Gaussian KL, mean tests, Gaussian likelihood ratios, and RBF MMD avoid absolute scale floors and premature overflow. Invalid FDR inputs remain visibly invalid. | Tiny/large-unit invariance and degenerate-distribution tests. |
| Graph structure | Required-edge MCMC starts inside the constrained space; latent projection retains original variable IDs, with Python adapters aligning names to the receiving schema. | Constraint, non-prefix observed-subset, and reordered Python identification regressions. |
| Expressions and identification | Repeated bound-variable multiplicity and nested-ratio domains survive simplification; bounded frontdoor searches disclose skipped subsets. | Evaluated expression equivalence/domain tests and frontdoor search tests. |
| Standard errors | Calendar HAC accounts for gaps and same-time covariance. IPW Hajek scores use target-specific nuisance derivatives, including clipping and trimming. | Hand-calculated HAC pins; nine case-weight finite-difference oracles with fully refitted logistic models. |
| Refutation and sensitivity | Replacement/permutation preserves missingness; leave-one-out kernel fits cannot use the held-out outcome as a fallback; contrast scaling/reversal remains consistent. | Missing-data, underflow, and positive/doubled/reversed-contrast regressions. |
| State-space models | Joint posterior paths retain temporal covariance; fitted baselines and parent effects persist in conditional mechanisms and their artifacts. | Incremental state | Invalid/degenerate particle updates do not silently produce uniform weights or partially mutate state; streaming covariance retains symmetry without per-row scratch allocations. | Atomic-failure, scale-invariance, and streaming covariance tests. |
| Attribution and design | Contribution variance survives large offsets; graph weight scaling does not change rankings; graph labels retain all 64 bits. | Offset 10¹²/variance 1, weight scales 10⁻³⁰ to 10³⁰⁰, sample-alignment, and label-collision regressions. |
| Resampling | Unequal-cluster bootstrap samples G whole clusters, with variable replicate row counts. | 4,000 replicates match analytic row-count probabilities 1/4, 1/2, 1/4; metadata and replicate offsets are checked. |
| Bootstrap execution | Cancellation preserves partial-result semantics and actual failure counts; nonfinite estimates are failures; adaptive stopping is invariant to units. | Pre-cancel, partial cancellation/early-stop, overflow, and scale-invariance regressions. |

For cluster bootstrap, the existing fixed-width buffer cannot represent unequal
replicate lengths. The new ragged batch API supports those draws directly; the
single-replicate and timeseries APIs also preserve variable lengths. The
fixed-width API continues to support equal-sized clusters and reports a shape
mismatch for unequal sizes. No licensed facade cell uses the latter combination.

## Engineering and performance

The corrections consolidate repeated numerical formulas and validators, remove
per-row covariance scratch allocations and repeated sandwich-matrix inversions,
and avoid witness construction for boolean d-separation. Calendar HAC replaces
full row-pair scans at every lag with ordered timestamp groups and in-band pairs.
Cluster bootstrap removes retry loops that both biased the distribution and
could fail to terminate promptly. Graph workers respect the configured thread
limit, and exact enumeration checks its memory estimate before allocating DAGs.

These are algorithmic and allocation improvements. They do not establish a new
release-profile throughput baseline or a hard bound on every workspace allocation.
No generic object hierarchy or broad interface rewrite was introduced solely to
satisfy a design acronym.

## Interpretation and limits

The regression tests target concrete mathematical counterexamples and public
behavior. They are not a proof of every causal identification theorem or
calibration of every estimator. The existing IPW analytic-interval calibration
was also run after its nuisance-score correction; broader scheduled calibration
and cross-platform wheel validation remain separate checks.

IPW analytic standard errors with trimming use a local, fixed-membership
derivative. Bootstrap refits additionally allow the retained membership to
change; the analytic result does not claim to capture that discontinuity.

The state-space sampler implements backward Gaussian conditioning for the joint
smoothing target, rather than independent marginal draws. The original plain
LGSSM variant remains available; the conditional variant retains the regression
baseline required by fitted parent-dependent mechanisms. Innovation packing
retains its existing f32 precision limit. See the updated
[LGSSM provenance](../provenance/model.lgssm.toml).

Primary references consulted include the
[NIST error-function identities](https://dlmf.nist.gov/7.4),
[Stan posterior-diagnostic definitions](https://mc-stan.org/docs/reference-manual/analysis.html),
[missing-observation HAC analysis](https://www.federalreserve.gov/pubs/ifdp/2012/1060/ifdp1060.htm),
and the [state-space simulation-smoothing paper](https://academic.oup.com/biomet/article-abstract/82/2/339/241063).
