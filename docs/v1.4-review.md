# 1.4.0 mathematical and epistemic review

Reviewed the changes introduced by `d17d66ad` against its parent, concentrating
on identification, graph completions, uncertainty aggregation, and the Python
handoff. Corrections are in the working tree.

## Corrected findings

- **Conditional identification:** the new graph-class routes inherited marginal
  ATE certificates even when adding the modifier conditioned on a mediator or
  opened a collider path. Each retained adjustment set now gets a pre-treatment
  and augmented backdoor-separation check. Failed checks retain unverified mass
  with a diagnostic; they are not a proof of nonidentifiability. The same check
  applies to the ordinary DAG backdoor route. The release fixture now correctly
  reports `GraphDependent`; its supported conditional estimate remains 0.40.
- **Frequentist uncertainty:** RMS component SEs are neither the sampling SE of
  a weighted estimator fitted to shared observations nor a complete graph-mixture
  standard deviation. Multi-atom SEs are now unavailable. Response intervals
  likewise no longer average endpoints into nominal confidence bands. A single
  contributing atom retains its uncertainty.
- **Temporal PAG scope:** enumeration covers only DAG endpoint refinements,
  excluding latent-confounded MAGs and a global equivalence audit. Results now
  disclose that restriction and cannot assert full-PAG point identification.
  Fixed tail marks on selection edges can no longer become arrowheads.
- **Temporal policies:** dynamic schedules no longer slip through the class
  estimator licensed only for pulses and single-step sustained interventions.
- **EconML handoff:** controls are sample-major `(n_samples, n_controls)`, with
  dimension and row-count checks. Temporal results refuse because the exported
  names discard offsets needed to align treatment and adjustment columns.
- **Evidence propagation:** diagnostics from unverified/refused completions and
  class limitations survive aggregation. Release notes, fixtures, and generated
  support documentation describe the narrower claims.
- **Build verification:** repaired an existing missing `CausalQuery` qualification
  in the Python temporal-mediation binding and stale refusal-message assertions.

## Mathematical basis and limits

For fixed weights, the variance of a weighted estimator is `wᵀ Cov(τ̂) w`.
Component SEs supply only the diagonal; they cannot recover the cross-fit
covariance. Graph-mixture uncertainty is a different object, requiring the
between-graph component as well. The implementation now withholds uncertainty
it has not calculated.

Conditional adjustment requires checking the conditioning variables, not simply
reusing an unconditional adjustment set; see [LaPlante and Perković (2024)](https://proceedings.mlr.press/v238/laplante24a.html).
The added check is deliberately sufficient, not a complete conditional-ID
search. It may refuse a query that a richer search could identify.

The EconML column convention follows its [API specification](https://github.com/py-why/EconML/blob/main/doc/spec/api.rst).
The temporal handoff remains unavailable until offsets can be preserved.

Completion-weighted means remain summaries under chosen graph weights. They
are not class-wide identified effects or identified-set bounds. Frozen numeric
pins verify the declared implementation; they do not prove identification or
frequentist coverage. Temporal PAG results remain restricted DAG-subset results.
