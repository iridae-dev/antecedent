# Antecedent 1.7 evidence

This ledger names the consuming tests for the 1.7 class-preserving temporal
surface. Identification, structural uncertainty, sampling uncertainty, and
empirical support remain separate axes. Enumeration weights are not a class
prior.

## Method boundaries

- PCMCI+ / LPCMCI edge strengths never become a class prior.
- Unidentified mass is not renormalized. Default `EnvelopeOptions` refuse
  `renormalize_identified_only` when unidentified mass is present.
- Bidirected MAG completions are unevaluable for sequential g-comp; that
  mass is retained as unevaluable, not dropped.
- TemporalPag natural mediation stays closed (cross-world theory).
- `execute_dbn_posterior_bayesian` stays `TemporalDag`-shaped.
- Mechanism priors cannot upgrade identification or invent class
  probabilities.
- Capped completion search cannot confer class-wide identification
  (`full_mass_scope`, `truncated_atoms`).

## Review regressions

The 1.7.0 review corrected implementation gaps without removing licensed cells:

- Observed Bayesian curves and Sequence now retain the observation specification
  and use the observed-data likelihood. Frequentist observation adjustment remains
  completion-specific. The selection regression includes unobserved sentinel
  outcomes and checks the recovered response against the observed linear law.
- Class priors bind to each completion and horizon. Binding normalizes finite
  positive mass before arithmetic; scaling a curve prior by `1e-99` or `1e308`
  preserves its result. Incomplete or capped coverage cannot publish a full-class
  mixture. No-prior Python class curves expose their sets without an implicit mean.
- Scalar and mediation atoms retain posterior artifacts. Curve atoms retain their
  complete response, including uncertainty. The artifact round-trip checks these
  fields, class mass, unfolded identification coordinates, and dose-major horizon
  support labels.
- Transferred mechanism priors bind separately against each completion's design;
  a valid transfer executes. Bayesian mediation uses independent mechanism random
  streams consistently with the existing DBN mediation path.
- Identification uses the actual Sequence schedule or mediation functional and
  audits every requested horizon. Prepared execution reuses those certificates.
  Python certificates preserve intervention and outcome time coordinates.
- Completion fingerprints include semantic node coordinates and isolated nodes,
  independent of dense node insertion order. Search caps remain explicit and
  cannot certify full-class identification.
- Full Bayesian validation without a class prior runs against finite atom
  baselines and retains atom predictive and sensitivity checks.

A second review pass on 2026-09-13 corrected the following, again without
removing licensed cells:

- Frequentist observation adjustment on incomplete classes carries the declared
  observation claims on the response and identification assumptions; adjusting
  the series per completion no longer erases them. Asserted in
  `temporal_class_observation_does_not_reuse_complete_band`.
- Class priors and stitched completion curves bind by completion fingerprint
  across horizons, not by enumeration position. A PAG window can retain a
  different completion set per horizon; an ordered prior and its pair form
  agree, and a horizon that enumerates a different membership refuses.
  Asserted in `class_curve_ordered_and_pair_priors_bind_the_same_completions`.
- Sequence and mediation identification on a bidirected MAG completion no
  longer inherits the Pulse enumeration witness. The completion is
  `GraphDependent` with `identify.temporal_class.bidirected_completion_uncertified`
  and its mass stays unidentified. Asserted in
  `bidirected_completion_does_not_inherit_the_pulse_witness_for_a_schedule`.
- Prior-transfer conflict summaries ride each completion posterior and the
  result diagnostics whether or not a class prior licenses a mixture, on Pulse,
  curves, and mediation. They never change identification.
- Frequentist multi-step class mixtures declare the missing between-atom SE
  with `estimate.envelope.se_omits_between_atom_variance`, as the Pulse
  envelope does, and carry the atoms' declared assumptions. Asserted in
  `frequentist_multi_step_class_mixture_declares_its_missing_se`.
- Frequentist class curves honor requested replicates on each completion atom;
  the class-level identified set still carries no band. Asserted in
  `frequentist_class_curve_replicates_ride_the_atoms`.
- `exec.identify.cached` is reported only when the prepared cache covers every
  requested horizon.
- Bayesian temporal Pulse / single-step Sustained report one registered
  estimator id, `bayesian.temporal.gcomp`, on `TemporalDag`, panel, DBN
  posterior, and incomplete classes. The `TemporalDag` path previously
  reported the Frequentist `temporal.linear.adjustment` and Python relabeled
  it; the class path reported the static `bayesian.gcomp`. Asserted in
  `bayesian_temporal_pulse_reports_one_estimator_id_on_dag_and_class`.
- Observed-data Bayesian Sequence atoms read the declared effect column when
  one exists and never index an absent posterior summary.
- A ClassPrior on ResponseCurve / InterventionResponse / mediation withholds
  `conditional_on_identified` when unidentified or unevaluable mass remains.
  The identified-conditional mean is not published by renormalizing away
  retained class mass. Asserted in
  `class_curve_prior_withholds_conditional_when_unidentified_mass`.

These regressions live in
`crates/antecedent/tests/temporal_class_bayesian_envelope.rs`,
`crates/antecedent-identify/src/temporal_generalized.rs`, and
`python/tests/test_temporal_class_bayesian_envelope.py`.

- Python and Rust both parse `conformance/bayesian/temporal_class_envelope`
  and assert weight basis / mass / cached identify.
- Artifact round-trip of `CallerSuppliedClassPrior` and temporal
  `structural_response` is covered by the native DTO fields on
  `AnalysisResult`.
- `scripts/gate_support_matrix.sh` must stay green with an empty allowlist.
