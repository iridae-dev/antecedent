# Predecessor controls

`2.4.1/manifest.toml` is the checksummed archive of the published 2.4.1 tag: source, wheels, crate versions, lockfiles, support snapshots, calibration files, artifact fixtures, and the benchmark commands that regenerate measurements. Wheel and crate bytes stay on GitHub, PyPI, and crates.io.

2.4.1 is a published predecessor (annotated tag, GitHub Release, PyPI wheels). Performance numbers are not frozen. B06 and B08 still have to record them. 2.4.0 remains the historical control (`2.4.0/README.md`).

Do not copy large outputs into git. Checksums in the manifest name the bytes that were published.
