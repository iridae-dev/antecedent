# Finite rollout/study-update binding

The equal-mass state law is theta=1/4 or 3/4. Waiting pays zero and betting
pays theta-1/2, so both prior expected utilities are zero and perfect
information is worth 1/8. Two independent Bernoulli(theta) observations have
predictive counts (5/16, 6/16, 5/16). Only count two licenses a positive bet;
its posterior expected payoff is 1/5, giving EVSI (5/16)(1/5)=1/16.

Rust and Python acceptance consume these hand-enumerated pins. The rollout
consumer reads the original source law and ranking, projects the named state
coordinate in draw order, and compares the complete terminal decision table
and source standing under independently retained expectations. An explicitly
named interventional predictive state preserves external/unverified trust;
source replay does not issue native execution authority or new calibration.
