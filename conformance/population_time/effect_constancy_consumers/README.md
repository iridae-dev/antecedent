# Original effect-constancy evidence in downstream consumers

The oracle in `expected.json` is independent closed-form algebra. It supplies inputs
and expected values to the executing Rust and Python tests; it is not a recorded
Antecedent response. A covariance-aware effect difference has variance .25,
standard error .5 and z=-2, hence two-sided p=erfc(sqrt(2)). The declared one-contrast
family leaves that p unchanged under Holm adjustment. Prior scores are negative
absolute effect distances; the original prior-bank compatibility check separately
excludes an outcome mismatch. Point policy utilities are exactly zero versus the
original effect, including equal-value ties and an empty intersection across
opposite-signed effects.

`crates/antecedent/tests/effect_constancy_consumers.rs` executes original F18
artifact consumption, the original bank filter/rank and original affine policy
engine. `python/tests/test_effect_constancy_review.py` exercises those consumers
and verifies original source replay in a fresh interpreter.

Source identity, original covariance and multiplicity family, fully supported
scientific coordinates and original partition provenance are mandatory. The
results remain point-only and unmeasured: they do not identify transport, authorize
posterior transfer or promise policy generalization. Calibration is a later gate.
