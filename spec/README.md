# Specification of the portable composition formats

This directory is the normative, versioned specification of three portable
formats and the evidence that a second implementation can consume them.

| File | Content |
| --- | --- |
| `interface-contract.schema.json` | JSON Schema (draft 2020-12) of the `interface_contract_v1` metadata |
| `evidence-ledger.schema.json` | JSON Schema of the `evidence_ledger_v1` metadata |
| `composition-bundle.schema.json` | JSON Schema of the `composition_bundle_v1` body |
| `canonicalization-and-identity.md` | container, CBOR profile, canonical writer, identity domains, versions and refusal classes |
| `conformance/` | fixtures generated by the Rust implementation (positive and negative), `manifest.json`, `blake3_vectors.json` |
| `consumer/validate.py` | clean-room consumer: Python standard library only, imports nothing from Antecedent |

Run the clean-room consumer over the fixtures:

```
python3 -I spec/consumer/validate.py
python3 -I spec/consumer/validate.py --kind interface_contract_v1 path/to/contract.artifact
```

The Rust gate is `cargo test -p antecedent --test specification_conformance`.
