## Run an example

```bash
python examples/python/feedback_three_questions.py
cargo run -p antecedent --example feedback_three_questions
jupyter lab examples/notebooks
```

The tutorials are the front door. Each follows one scientific task and pairs with an example in the Tutorials table below; the [documentation home](../docs/index.md#tutorials) lists them by task. Start with [an observational study](../docs/tutorials/observational-study.md) or [one feedback system and three questions](../docs/tutorials/feedback-three-questions.md).

## Datasets

Most examples simulate their data from a declared mechanism so the known answer can be checked. Examples that read a real public dataset describe its origin, licence, version and checksums in [`data/`](data/README.md), and run offline on a labelled synthetic stand-in. The published site includes executed notebook previews; the source notebooks remain free of saved outputs.

<!-- generated:example-catalog:begin -->

Examples run on simulated data with a declared mechanism, so the known truth can be asserted; a simulated truth is a fixture truth of that stated model, not a claim about a real system. Two tutorials read a real public dataset on request and fall back to a synthetic stand-in offline; each says in its output which table it used. Runtime estimates assume a warm installed environment and exclude installation and Rust's first compilation. First native imports and notebook-kernel setup can add substantial time; machine, workload and optional dependencies affect elapsed time. Assertions check each example against its stated truth, not your causal assumptions.
